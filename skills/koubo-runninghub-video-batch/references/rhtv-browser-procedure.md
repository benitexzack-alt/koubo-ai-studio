# RHTV 浏览器执行规程

本规程用于 RHTV 画布的受控图生视频节点填充。使用前先读取 Browser Skill，并优先复用已经登录、已经绑定的目标画布标签。

## 预检

1. 只读核对画布 URL、余额、运行状态和目标图片文件名。
2. 记录全部有效图片版本。文件名带修订号时，旧版本仍可保留，但不得误选。必须确认文件名位于 `.react-flow__node-rh-image` 图片节点；聊天附件、上传浮层或未发送的文件名不算画布节点。
3. 确认本轮授权是否包含上传、节点创建、填写或生成；没有包含的动作不得执行。

## 单节点可靠顺序

1. `添加节点` → `视频`，创建一个视频节点。
2. 在节点内选择 `首帧`。
3. 点击节点的 `添加`，在引用选择器中选择 `图片`。
4. 使用 `搜索节点名称` 精确搜索目标图片文件名，只在结果唯一时点击 `添加引用`。
5. 关闭引用选择器，读取 React Flow 可见 DOM，确认图片节点与视频节点之间出现唯一边。
6. 在节点提示词输入框填入清单原文，立即回读并逐字比较。
7. 此时回读当前模型。若不是 `MiniMax H3`，打开模型选择器并执行 `MiniMax` → `MiniMax H3`；若已经是 `MiniMax H3`，保留当前值。不要选择 `MiniMax H3 Max`。
8. 设置 `2k`、该镜时长、清单画幅。大小写显示差异可以接受，但数值必须一致。
9. 检查提示词优化按钮 class 为 idle，不能处于处理中或已改写状态。
10. 回读节点：必须同时出现 `MiniMax H3` 与正确参数；图片引用边仍存在；提示词仍逐字一致。
11. 检查页面没有“生成中”“排队中”或“任务已提交”，余额未变化。
12. 不点击 `开始生成`。

## 已验证的 RHTV 行为

- 直接从“添加节点 → 视频”创建手工节点不会自动运行。
- 通过图片引用建立连接后，节点可能重置为默认模型，也可能保留上一节点的 H3；必须在图片绑定之后回读并按需修正，不能依赖继承值。
- RHTV Agent 对话创建节点可能立即提交，且请求的模型不一定被宿主采纳。正式批量填充禁止走 Agent 对话。
- 画布可能同时保留旧图和修订图；文件名是选择权威，不能依赖缩略图肉眼猜测。
- 聊天输入区上传不保证形成稳定画布节点。找不到修订图时，应先用“添加节点 → 图片 → 上传”建立正式图片节点，再从视频节点引用；不得把临时附件可见当作绑定完成。

## 批次节奏

- 逐节点顺序填写，避免多个打开的选择器或参数面板互相污染。
- 每个节点通过回读后再开始下一个。
- 任何一镜失败，停止后续节点；保留已通过节点，不删除、不覆盖。
- 整批完成后先交付回执和画布状态。生成授权必须与填充授权分开。
