## 每镜只讲清一个意思，但让过程真正发生

- 首帧是动作前的静态初态，直接准确生成 `textPlan` 中的中文；写清每段字所在的纸面，不再先造空牌再本地烘焙。
- 首帧已有文字不代表结论必须提前成立。机构的初态、关系和结果要有可见差别，不能所有结果已画好，只晃一下相机。
- 视频词继承同一张首帧、字形、物件和材质，描述动作如何推动结果。允许有前后顺序和有因果关系的并行动作，不限定每镜同一秒数模板。
- 文字与物件同动不是所有字都必须动：场景标题可固定；移动卡片上的字不能留在原位。固定标签须说明实际用途，禁止把全部标签改成固定牌作为默认避险。
- 字形保持不变，不等于位置不变。允许纸面透视、翻页和合理遮挡；重要文字不能跨折痕扭坏，短暂背面不可见不算丢字，回到正面须仍是原字。错误时只修失败镜头，不冻结全片文字。
- 结尾留足正常速度可读的时间（约一秒是参考，不是所有镜头的定额）；读不清先调整排布与节奏，不自动删成三个标签。
- 纸艺说明不是事实证据。事实核验、真实素材来源、实录字幕和用户批准均不因此放宽。

## v2 导演字段与交接

`styleLocks.paperEditorial`：`qualityBaselineId=paper-super-individual-20260829-v1`，`textPolicy=first-frame-generated-chinese-surface-bound`。参考图仍须真实路径和哈希。

每镜 `textPlan` 允许一至九条短标签，每条不超过八字；这是输出边界，不是数量目标。每条包含 `text`、`surface`、`motion`（`with-object` / `fixed-context`）；固定项加 `reason`。首帧词中必须同时包含准确文字与对应纸面。

每镜另有 `motionPlan`：

```json
{
  "goal": "同样的工具经过组织，才能形成交付",
  "actions": ["带字工具卡进入托盘", "托盘推动联动齿轮", "结果卡落定"],
  "result": "工具通过结构连接到结果，而非只是堆放",
  "textBinding": "surface-bound",
  "audioPolicy": "preserve-usable-native-action-sound"
}
```

它记录导演意图，不是物理仿真合同。实际视频必须复核是否真的发生，填字段不能自动合格。视频词应明确文字随对应物件同步运动、禁止乱码/漂字，以及只保留纸艺动作音、不要配乐和旁白。

导演确认后，直接用官方 v2 交接中的纸艺首帧 child 执行带字首帧；动作 child 只供图生视频。新路线不调用旧无字底图桥接、确定性写字器、固定字牌物理合同或本地动画渲染。旧脚本拒绝新路线是防误用，不是要求把提示词改回旧格式。

首帧仍要逐图看图、核对指定中文并保存 OCR/人工复核及文件哈希；用户确认后才可生成视频。外部上传、提交、付费和重试须按本轮授权，不能用导演或结构校验通过冒充授权。交接仍保留任务、版本、首帧、视频词一一配对，未经验证不伪造旧 ready pack。

## 动态与声音验收：和基准并排看

每条素材入片前，按实际文件记录：

1. 正常速度观看：能复述“输入—动作—结果”，不是只有镜头移动或整体缩放。
2. 检查带字物件的动作前、中、后及遮挡/翻页边界：文字随物件走，没有字牌留在屏幕上、字形漂变或遮住关键节点。不能只看首中尾三帧。
3. 与参考素材比较空间层次、纸材质、机构动作和阅读节奏；用户对代表镜确认后再扩展。同类后续镜仍逐条验收，不自动继承通过。
4. 听原素材，再听口播混音：分别记录原生动作音保留/局部处理/静音及理由；缺少原生音时才配对应动作的补充音效，避免同一动作叠两次。历史纸艺音量 `0.10` 只是该片混音值，不作全片统一音量。
5. 新片字幕与切点仍按实录；旧片完整音轨不直接复制到新片。

未来升级只替换实际改善的部分，和此基线做同场景对照，未经用户确认不得把更简陋的候选提升成新的默认。代码/文档回归只能证明规则一致；下一条真实视频仍需视觉与听觉验收。
