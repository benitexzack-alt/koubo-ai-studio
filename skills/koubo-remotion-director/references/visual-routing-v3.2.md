# 导演视觉路由 v3.2

## 一、四种主画面与一种信息层

1. `speaker`：观点、判断、转场、风险提醒、个人立场与结尾互动。
2. `real-evidence`：用户提供且完成授权、身份和内容核验的真实视频、录屏、官方资料或地点。
3. `generated-video`：没有真实素材时，用于人物、行为、环境和情绪的情景演绎；固定为 `illustration-only`，不能充当事实证据。
4. `paper-editorial`：解释因果、流程、结构、对照、层级和关系变化。
5. `remotion-information`：只作为章节、关键词、来源、风险说明或 CTA 叠加层，不能替代主画面类型。

不按数量配额硬凑。每个节拍只按口播的表达任务选择主画面。

## 二、真实素材讲解小窗

当本人正在解释某一段真实素材时，使用 `real-media-with-presenter-inset`：

- 素材占主画面；同一权威口播原片的视频副本在 8—16 帧内缩到右下角。
- 权威口播原片始终是唯一人声来源；右下角视频副本必须静音。
- 右下角默认圆形 296×296，距右 72、距下 188；必要时用圆角矩形。
- 字幕与人物框最少间隔 24px；主素材右下角有关键内容时改位或放弃小窗。
- 素材原声必须显式选择 `muted`、`duck-under-narration` 或 `feature-audio-window`。
- 片段短于 2.8 秒、真人手势是重点、素材自带人物小窗、多人主要对白、版权隐私未确认时禁止触发。
- 任何裁脸、口型不同步、双重人声或字幕遮挡都必须回退为全屏真实素材或主播主画面。

参考实现位于 `assets/remotion-presenter-media/PresenterMediaStage.tsx`。它是隔离能力，不得通过改写共享 V8 组件接入。

## 三、纸艺带字首帧

模型只生成无字纸艺基础图。最终送入 RunningHub 的首帧必须经过：

```text
无字基础图
→ 实际纸面四角标定
→ 本地确定性写入中文
→ 每标签OCR逐字相等
→ 带字联系表人工确认
→ runninghub-ready-pack.v1.json
```

导演计划中的纸面坐标只是构图意图，不能替代实际图片标定。带字纸片只允许刚性滑入、平移、小角旋转、抽屉推出和拼图扣合；禁止折叠、弯曲、卷曲、拉伸、翻面和重写文字。

## 四、AI生成视频

- 只在需要具体人物、行为、环境或情绪，且没有合适真实素材时使用。
- 默认全屏播放，并保留 AI 内容声明。
- 不能证明客户、收入、需求规模、政府事实、真实案例或交付结果。
- 一旦用户提供内容相符且授权明确的真实素材，优先切换为真实素材；正在讲解该素材时再判断是否使用右下角真人小窗。
