# V4 旧卡片包退役说明

## 状态

`retired-reference-only`

本文件只保留旧 V4 路径的名称和退役边界，便于识别历史任务、防止回退。它不是当前导演 Skill 的必读执行指南，不得从本文件实例化新分镜、静帧或动态样片。

## 已退役的场景语法

下列做法均不再作为高级包装默认方案：

- 固定左上标题条、定义大字卡或场景编号 UI；
- 三列等权卡片、固定高度卡片和翻卡式 PPT 叙事；
- 通用脑图、粗线连接和用文字标签代替实体物件；
- 评论浮层、行动输入卡等每条必须覆盖的固定组件清单；
- 为了“覆盖组件类型”而生成与实录语义无关的画面。

## 现行替代路线

新任务以 `paper-editorial-style.v1.json` 为风格合同，并依语义选择：

- `complex-explanation`：多物件、多节点和分级装配的摄影级纸艺微缩场景；
- `mechanical-causality`：只在连续可见机械动作成立时使用；
- `occluded-state-reveal`：只在完全遮挡期间切换已绑定状态，不冒充机械关节动画；
- “摄影级完成态状态图 + 确定性真实证据/中文合成 + Remotion 局部动画”的混合管线。

现行细节以 `SKILL.md`、`paper-editorial-style.v1.json`、`acceptance.md` 和 `validation-gates.md` 为准；本退役文件不得覆盖它们。
