# V4 视觉实验包

## 使用场景

下一条正式口播默认从 V4 实验开始。旧 `mind-map / perspective / metric / flow` 只允许作为简版兜底，不能作为高级包装默认方案。

## 五类组件

### 1. 定义大字卡

用途：解释一个概念、身份或判断。

要求：

- 一屏只解释一个核心词；
- 大字必须来自口播语义；
- 副文案最多 1-2 行；
- 不压脸，不压底部字幕；
- 入场有帧驱动动效，不只是静态淡入。

### 2. 三列能力卡

用途：展示三类能力、三种资源、三步路径。

要求：

- 三列宽度和视觉权重稳定；
- 每列标题短，说明可读；
- 长文案自动缩字号或换布局；
- 不用固定高度裁切；
- 三列依次进入，避免同时堆满。

### 3. 资源导向脑图

用途：表达从本地场景、技能、工具、算力或交付之间的关系。

要求：

- 节点数量超过 4 个时改为动态布局或分段出现；
- 箭头/连线必须有方向感；
- 任何节点不得被 `overflow: hidden` 吞掉；
- 复杂节点必须设置 `reviewAt`。

### 4. 评论/案例浮层

用途：承接真实评论、问题、用户反馈或脱敏案例。

要求：

- 没有真实来源时只能写“典型问题”，不能伪造评论；
- 截图、聊天、客户信息必须脱敏；
- 浮层是辅助证据，不抢主体口播；
- 如含 AI 生成或改写，按平台规则如实标识。

### 5. 行动输入卡

用途：结尾告诉观众下一步提供什么资料、做什么动作。

要求：

- 只给一个行动引导；
- 不承诺保证获客、成交、涨粉或投放效果；
- 不做站外违规导流；
- 可以列 2-3 个最小输入材料，如“行业、产品、一个重复流程”。

## 参考图落地规则

参考图只能抽象学习：

- 信息层级；
- 构图节奏；
- 色彩和光影关系；
- 动效方向；
- 缩略图可读性。

不得复制参考图的原文案、Logo、人物、品牌界面或完整构图组合。

每个参考素材必须在 `visual-plan.json` 里绑定：

- 原创组件变体；
- 对应口播节点；
- 验收帧 `reviewAt`；
- 通过/不通过标准。

## V4 预览验收

正式全片前，预览必须覆盖：

- 定义大字卡；
- 三列能力卡；
- 资源导向脑图；
- 评论/案例浮层；
- 行动输入卡。

若本条内容不需要某一类组件，在视觉方案中写明“不适用原因”，不得空缺不解释。
