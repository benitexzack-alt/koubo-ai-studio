# AI情景视频：导演评估与提示词交接

适用于每期全文导演规划。参照20261023期五支AI情景的实际交付，补齐与代码插片并行的素材分路；成片继续使用V9，不改变原声、字幕和后期基准。

## 先判断，明确写出结果

- 每期全文导演表必须写明AI情景“采用”或“不采用”，并给出对应原句、具体理由。完全没有评估，不能当作已经判断不需要。
- 机制、因果、比较、流程和路径通常适合代码插片；具体工作动作、人物互动或环境体验能让原句更易理解时，可以选择AI情景。无需先证明所有代码画风都无法表达，不按固定数量或间隔凑镜头。
- 不采用时说明本期真实理由，例如真实录屏已完整展示操作、抽象关系用代码更清楚、情景不增加理解。不得复制空泛理由，伪造已听审、已评审或已核验来源。
- AI情景只作说明，不作证据。不重演真实企业、客户或员工的未核实行为，不用虚构画面证明人数、收入、交易、效果或平台能力。必要的真实证据仍走真实素材分路。

## 两路分别交接

`insert-shots.plan.json`只交代码插片，不加入AI情景字段、提示词或平台参数。全文导演选择了AI情景时，同次向用户交付本期`03_导演交接/AI视频生成提示词.md`；已有导演目录沿用原位置，不为规范名称另建重复工程。

视频提示词独立编号`A01、A02……`，交回`A01.mp4、A02.mp4……`。无需首帧提示词、首帧生成或RunningHub参数；不自动替用户打开生成会话、上传素材或调用生成服务。仅在具体生成路线另有明确要求时再处理额外步骤。

## 每镜交付内容

| 内容 | 要求 |
| --- | --- |
| 原句与用途 | 引用对应原句，说明观众从该镜看懂什么；不新增原话没有的结果或承诺。 |
| 插入锚点 | 无实录时写原句起止和文字锚点，精确入出点标为待实录绑定；有实录后按原声绑定时间，不假造拍前秒数。 |
| 两种长度 | 分别列生成长度与实际剪入长度。可为选帧留少量前后余量；没有实录时实际剪入长度保持待定。 |
| 可复制提示词 | 每镜提供一段完整文本，包含场景、人物、初始状态、开始动作、关键变化、结束画面、机位、光线和连续性；不能只让用户去拼其他文件里的通用条款。 |
| 画面保护 | 写入本期左下真人与底部独立字幕区，主体、关键动作和文字避让；不把真人或口播字幕预先生成进素材。 |
| 声音 | 不加解说、对白或背景音乐；需要时保留与动作相符的环境声、拟音。Codex回收后按原声清晰度决定保留、压低或静音。 |
| 交回文件 | 明确镜号、文件名、本期唯一项目内的`01_素材投放区/03_AI情景视频/`实际路径，以及尺寸、帧率和时长要求。 |

优先交回1920×1080、30fps原始MP4；平台规格受限时保留最高可用原件并告知实际规格，由Codex在回收时判断适配，不要求用户自行拉伸或裁掉人物。

## 每段可复制提示词都应包含

1. **主体与动作**：虚构普通成年人物、具体环境和可见物件；从稳定初态开始，用清楚的动作变化结束在可剪接画面。身份、衣着、物件、空间和运动方向保持连续，手部动作不宜过密。
2. **机位与光线**：写清景别、固定或移动方向、自然光或其他明确光线；镜头动作服务原句，不默认使用炫技运镜。
3. **事实边界**：明确是通用情景演绎；不仿造真实客户、品牌、合同、聊天、付款或成果。无必要时不生成可读文字、数字、Logo、二维码和个人资料。
4. **后期安全区**：当前横屏V9起点为左下`x=32–500、y=584–884`仅留平静背景，底部`y=900–1080`不放关键物件或文字；关键人物和动作放中右区域。本期布局变化时同步改具体数值，不能沿用失效坐标。
5. **声音与标识**：不含额外解说、对白和音乐，可有自然环境声；保留平台原生AI标识及元数据，不生成假实拍署名。Codex剪入时另加清晰的“AI情景演绎”标识，不要求生成模型绘制该文字。

情景出现时，本条同期真实主讲持续放在左下小窗，口型连续且平滑缩入、回归；字幕在独立区域。转场、字幕、真人、配乐和最终混音由Codex完成。

## 交付前的人工核对

- 全文是否实际评估了AI情景，并留下采用或不采用的具体理由？
- 选择的每支AI镜头是否同次提供了完整可复制提示词、原句锚点、两种长度、文件名和实际回传位置？“已经需要但提示词未交”应明确记为交接未齐，不能让用户再次提醒。
- 代码JSON与AI提示词是否各自清晰，且选中镜头在全文导演表中有对应位置？
- 是否把无实录的时间保留为待定，并明确生成画面不具备事实证据资格？

以上是导演交接核对，不是新增机器门禁，也不证明素材已生成、画面质量合格、用户已观看或成片可公开发布。回片后再核对实际画面、动作、声音、安全区和实录时窗，只返工失败镜头。
