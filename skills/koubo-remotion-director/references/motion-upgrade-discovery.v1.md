## 拍后候选比较与实际兑现

完整目录扫描继续遵守项目规则；先通过目录和元数据找出与本句相关的候选，再看这些候选的真实预览、时间轴和源码。扫描数量只证明覆盖范围，不能证明选择合适。对进入动效匹配的段落，不得在查看相关候选前预填“现有效果足够”。

按以下顺序执行，记录放在本条任务已有的选型或验证说明中，不给 v2 导演 JSON 新增字段：

1. **确定表达需要。** 记录实录原句、片段区间和导演 `reason`，说明是并列、对照、流程、汇聚、分支还是证据聚焦，以及现有版的具体不足；没有不足也可如实保留。
2. **比较相关候选的实际动作。** 对现有效果与相关的已购库/阿杜候选，记录版本与源码位置、实际运动、内容容量、人物与素材依赖、可保留的动作和必须适配的差异。名称、海报、关键词命中和静态截图不足以完成动作比较；无需为凑数量加入无关候选。
3. **逐项给结论。** 使用“采用”“不适合”“适合待适配”说明本条选择。“不适合”须写具体语义或素材原因；“适合待适配”须写缺失依赖及最小适配范围，不能偷换成已经采用或“不需要”。这是选型说明，不替换正式回执的 `apply/not-needed` 枚举；标为 `apply` 的选型记录不等于实际应用完成，仍须后续实现与验证。
4. **让所选动作实际发生。** 将采用项对应到本条实现文件、函数/组件、原句触发点和实际输出区间；说明保留了什么识别性动作、改变了什么。只改标题、颜色或统一换成列表不能宣称已吸收原效果。源码含有但未被本条调用，同样不算使用。
5. **检查本条结果。** 对照同一实录区间，检查对象是否连续、关系是否讲对、动作是否完整、文字是否读清、真人与字幕是否被挡，以及音效是否落在真实动作上。保存动作前/中/后的连续帧与正常速度片段，明确实际观看和试听范围；技术检查、抽帧和自动播放不能代替用户观看。

每个采用项至少能追溯“原句 → 动作描述 → 候选依据 → 实际实现 → 输出区间 → 观察结果”。涉及声音改动时先保留同源口播、明确原声与新增声音，避免把音量变化当成视觉升级的证据。允许无音效，允许全部候选不适合，禁止为证明会员费有价值而硬塞效果。

交付真实画面与同窗对照供用户审阅；若只是工程适配成功或尚未确认理解增益，标记为候选。用户认为无明显收益时保留现行版本，不以测试通过、效果数量或新版本名称反驳观看结论。

## 避免把导演选择退化成通用字卡

用户在2026-10-06退回R1的“大白底板＋几行黑字”。它省略了不同参考效果的真人前后层、真实图像和场景运动，不能作为升级默认或合格审美证据。R1仅留作历史候选，不再优先推荐。

按“实际说词 → 观众要看见的变化 → 能保留这种变化的效果 → 真实素材与人物/字幕净空 → 声画落点”选择。先读效果实际时间轴与必要几何；名字、封面截图或目录分类不足以证明会用。用户点名效果时必须保留其识别性运动，缺少依赖就如实标记，不能省掉后再以同款字卡冒充。

- 数量主题钩子：真人背后大字需连续底片、同帧人物alpha、相同定位/裁切/帧点；人像不能用静帧或小窗代替。真实浏览器里还须检查两个视频层处于相同绝对定位，避免透明视频排到下一行、文字反而盖脸。
- 被逐个点名的产品：使用真实产品图卡、按实际说词逐卡进入、整卡有重量地落定；不只显示三个黑字，不编图标/界面/能力评分。产品标签不反改实录字幕。
- 章节切换：保留参考的中心向外铺格与反向撤格；普通fade或电子横移不能冒称方格转场。真正平面巡读与方格转场分别判断，不能混用名字。
- 对照、合包、分支：先判断是同维度比较、多个输入汇为一个交付，还是并列用途；不要把所有关系都写成线性流程。数字必须有同口径真实来源，不能为了使用图表编值。

V9 继承 V8 的同一父对象、读稳停留与因果动作要求；非必要不切整页、不反复清空。原包元素上限须检查，十项不能被静默截为3/4/6/7/8项，也不能缩字塞满。真实图像、抠像或场景变化正是效果的内容时，不得删掉这些依赖留下统一白板。所作适配差异须明确，不把局部适配称为原版完整复现。
