# 口播插片导演核心 v1

## 唯一任务

把一份完整口播文稿变成少量、准确、可执行的插片决策：

```text
完整文稿 → 该不该插 → 插什么 → 首帧提示词 → 图生视频提示词
```

本环节不负责生图、图生视频、Remotion 动效、字幕、音效或正式渲染。

## 判断方法

### 1. 全文优先

一次读完全文，先写出主观点和论证顺序，再选择插片。不得按固定字数、固定秒数或逐句独立调用模型。相邻节拍要去重，不能连续用相同视觉隐喻解释近义内容。

### 2. 先路由，后写提示词

按以下顺序判断：

1. 需要证明事实、数字或“有人这样说”吗？使用真实截图、原始材料或权威素材。
2. 需要展示真实人物、产品、地点或操作吗？使用真实或官方素材。
3. 需要解释机制、流程、关系、层级或对比吗？才使用纸艺 AI 插片。
4. 只是气氛、装饰或重复口播吗？不插，保留真人。

`director-cues.v1.json` 的 `inserts` 只收录需要生成的 `paper-editorial` 插片。真实证据位置写入 `selectionSummary.realEvidenceSuggestions`，只记录原文短句、素材类型和使用理由；不得伪装成生成镜头，也不得在导演阶段提前搜索或制作素材。

钩子、本人经历、情绪转折、风险边界和结尾行动号召，默认由真人承接。

### 3. 每镜只增加一个理解

每个候选插片必须回答：

> 观众看完这一镜，比上一秒多明白了什么？

没有明确答案就删除。把答案写进 `reason`，把可见的物理表达写进 `visualMetaphor`。一镜只保留一个中心隐喻和一个 `primaryAction`。视频词出现“随后、然后、接着、继而、再把、再将”等第二阶段连接词时，必须拆镜。

### 4. 风格锁只建一次

从用户确认的参考图或往期优质片中提取一份 `styleLock`，至少包含：

- 摄影类型：实体桌面微缩摄影，不是矢量信息卡；
- 材料：纤维卡纸、瓦楞纸、撕边纸、胶片、纸钉、棉线、金属夹等真实可触材料；
- 空间：至少三层深度、真实接触阴影、前后遮挡和适度景深；
- 光线：统一方向的柔和侧光；
- 色彩：系列主色保持稳定，但不同镜头不能只换文字；
- 禁止项：PPT 卡片、扁平 UI、塑料 3D、随机霓虹、连续相同流水线、模型生成可读文字。

参考图必须作为独立输入资产绑定；不能只在文字里说“参考某种风格”。实际投喂必须使用干净单帧，不能使用带窗口控件、黑边或九宫格的联系表。参考只用于材料、空间、光线和装配机制，不复制第三方具体版式、照片和镜头顺序。

同一材质语言不等于同一构图。相邻镜头的 `composition` 必须不同，可以在环形观察台、放射式编辑桌、侧视纸桥、对角地图、微距错位机构等语法之间选择；不能连续使用左中右三栏桌面。

### 5. 两类提示词分工

首帧提示词只描述静态初态：

```text
风格锁 + 镜头机位 + 中心物件 + 前中后景 + 动作前状态 + 禁止项
```

不得出现“随后、然后、逐渐、最终、滑入、展开、旋转、变成”等过程或结果词。

图生视频提示词只描述动作：

```text
基于已确认首帧 + 一个主动作 + 必要运镜 + 明确结束状态 + 保持项 + 禁止项
```

不要重复材料清单和完整场景，不要让视频模型重新造景。默认固定机位或一次轻微推拉；声音由后期处理时，不要求模型生成对白、旁白或背景音乐。

### 6. 中文纸面信息单独输出

参考风格中的短标题、节点和关系词属于解释层，不能全部删掉，也不能让生成模型直接写。每镜在 `textPlan` 中保留一至四个短中文标签，每个不超过八个字，并用 `surface` 指向首帧词中已经出现的独立固定空白纸牌；首帧自动化再对该纸牌确定性写入中文。这里只写文字与载体名称，不写坐标、字体像素或 OCR 参数。

### 7. 锚点就是实际画面窗口

`scriptQuote` 只保留插片真正覆盖的逐字短句，`startAnchorText` 和 `endAnchorText` 按原文顺序定位入点与出点。预拍时长不得短到无法容纳该短句；上限按每秒八个中文字符估算。拍摄后以真实口播声音重新绑定，入场落在关键词上或稍后，禁止提前。

## 输出和自检

输出使用 `templates/director-cues.v1.json`。提交用户前检查：

- `scriptQuote` 是文稿逐字原句；
- 真实证据建议引用原文短句、类型正确，且没有被伪装成纸艺生成镜头；
- 插片顺序与全文一致；
- `startAnchorText`、`endAnchorText` 能定位原文；
- 原文短句与时长相容，首尾锚点顺序正确；
- 每镜的 `visualMetaphor` 唯一；
- 相邻镜头的 `composition` 不重复；
- 首帧词确实包含风格锁，但不含动作结果；
- 视频词以已确认首帧为基准，只含一个 `primaryAction`，没有第二阶段连接词；
- 中文节点只出现在 `textPlan`，每个节点都绑定首帧中的固定空白纸牌，不交给生成模型；
- 两类提示词均不含毫米、坐标、哈希、OCR、碰撞或布局合同；
- 没有为了数量强行插片。

## 方法来源

以下开源项目只用于方法对照，没有复制其第三方参考素材：

- [Showrunner](https://github.com/doziben/showrunner)（MIT）：全文拆成自然语义组，钩子/情绪/CTA 留真人，高信息内容切 B-roll，严格结构化输出。
- [DirectorSKILL](https://github.com/wuwangzhang1216/DirectorSKILL)（MIT）：镜头必须产生新增理解；关键帧是控制点；风格是一份覆盖层；一个短镜控制动作预算。
- [B-Roll-Finder](https://github.com/erfsalehi/B-Roll-Finder)：全文一次性导演、输出意图/类型/位置/优先级，不再逐小段孤立生成。
- [EverythingAI-Pro/ai-video-editor](https://github.com/EverythingAI-Pro/ai-video-editor)（MIT）：B-roll 表达观点而不是追逐关键词；真实证据、实体、抽象概念分流；画面落在词上或略后。
- [Marinara Storyboard Agent](https://github.com/Pasta-Devs/Marinara-Engine/blob/main/docs/game/storyboard.md)：规划、首帧格式化和视频动作格式化分层，避免一份提示词承担所有职责。
- [抖音：完整口播剪辑流程](https://www.douyin.com/video/7561783565861522742)、[图生视频提示词复盘](https://www.douyin.com/video/7587225361230974260)、[参考视频拆分镜与动画提示词](https://www.douyin.com/video/7572105710336288484)：只作为公开视频工作流线索，用于核对“全文节拍、关键帧、动作词、人在回路”的共同做法；不把评论或二手转述当规则。

最终判断仍以本项目往期优质成片和用户观看结果为准，开源项目名称、星数或 README 不能替代实片验证。
