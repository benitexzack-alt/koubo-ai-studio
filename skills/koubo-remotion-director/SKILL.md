# 口播全片语义导演

> 2026-10-18 用户确定新流程：纸艺/像素由 Claude Code 直接用代码生成视频。本文件和[插入镜头交接规范](references/code-insert-shots.v1.md)是这两路当前权威。
> 成片仍为 V9；历史导演 V9.1、`koubo-director-cues/v2` 保留兼容名称，不启动 V10。

## 阶段和唯一交付

- 阶段为 `director-only`。先读完整确认文稿或真实转写、用户风格参考、本文件和插入镜头交接规范。
- 给 Claude 的唯一文件：`edit/generated-video/<episode>/insert-shots.plan.json`，严格沿用用户字段，不增加首帧词、图生视频词、平台参数、审批状态或哈希。
- 拍前可以分析全文、选原句和视觉意图；正式 `insertAt/enterSec` 必须在实录后绑定，没有真实时间证据不能填估算值冒充精确值。本轮只有参考片而无新一期正文时，只更新规则/模板，不擅自重做历史片。
- 不启动生图、首帧 OCR、RunningHub、Claude 会话、付费调用或渲染。用户把方案交给 Claude，本 Skill 不代替用户发送外部消息。
- 结构检查不证明语义、实录对齐、视觉效果或生成完成。每期方案仍供用户审阅，已有本期明确授权不重复询问。

## 全文导演判断

先明确全文主观点和论证顺序，再逐段选观众需要看的内容：

1. 真人：本人判断、信任、情绪、边界、行动号召，或其他画面不增加理解时保留主讲。
2. 真实素材：官方原文、真实操作、产品、场所或证据本身必须看见时使用，独立锁定来源和权限。
3. 纸艺 `paper`：用可触物件和空间关系解释业务机制、输入输出、因果、层级、对照和服务交付。
4. 像素 `pixel`：用人物、地图、方块、关卡和移动表现任务推进、路径分叉、资源传递和人工把关。

两种画风由导演选择，可以在一期穿插；切换服务语义转折，不能因为有两个模板就机械交替。`pixel` 主题只用 `noir/blocks/mono`，`paper` 用中文一句话描述主色调。

用户要求更积极使用有帮助的插片：主动复核长真人段中的信息密度、比较和流程，不因旧“少量插片”、费用顾虑或2–8秒限制而机械压缩；也不设固定数量/间隔。候选不适配时重新判断可用的纸艺/像素表达，不只写“不适配”就留下长空档。没有解释收益仍保留真人。

事实核验与画面选择独立。数字、倍数、价格、平台能力、因果和绝对化主张仍在本条事实锁中核对。插片只作说明，不能替代来源、实拍或实测，不能借画面升级未证实主张。

## 每镜写准

- 一个镜头解决一个认知目标，可以包含有关系的连续动作；交代对象、初态、变化、结果和阅读停留。
- `spokenLine` 保留实际说法；`title` 和3–5个中文节点只提炼原句已有意思。节点按画面左到右排列，每个 `label` ≤6个字符，Claude 原样排字。
- `object` 只写看得见的物件和动作，不写“赋能、升级”等抽象命令。`flow` 写关系传递，原话是并列就明确并列，不能画成强制因果或前后工序。
- `ending` 写最后落定画面和读字停留；最后标签刚出现不能立刻切走。
- 标签绝对入点 = `insertAt + enterSec`。用音频/SRT/词级转写核对；只有句级 SRT 时听审窗口定位关键词，禁止平均分配时长冒充精准对词。
- `duration` 与交回 MP4 画面帧数/30一致。剪辑重排后重新绑定时点；不拉慢真人或冻结长段插片凑时长。
- `avoid` 每镜写明左下真人区、底部字幕区和禁用物件，直接交给 Claude，不能只放内部笔记。具体字段、避让起点和验收见[交接规范](references/code-insert-shots.v1.md)。
- 改写公开可见标题/标签时遵守项目文案双 Skill；原样搬运已确认文字不重复改写。审稿记录不加进用户 JSON。

## V9 与剪辑交接

- 同一对象有意义时连续承接，动作与阅读分开，语义不需要时允许自然收场。不能机械每句清空或为了连续而硬连。
- 插片期间本条真人同步缩入左下小窗并连续播放，平滑交接，结束后回归。不得冻结人脸、移到右下或直接去掉主讲。
- Claude 只生成插片本体；字幕、真人小窗、转场、配乐和最终混音由 Codex 完成，不预先烘进插片。
- 保留拟音原轨，按口播清晰度和正常速度试听选择保留、压低或静音，避免与后补音效重复。本次授权允许静音，旧原生音效条款不能阻断新路线。
- Shotcraft 仅对真人/真实素材记录功能意图及完整原因，拍后按实录和保护区扫描相关库；不在纸艺/像素内部再叠加。具体效果选择不在拍前进行。

## 校验和回收

```text
完整文稿/实录 → 全文判断 → 实录对词与时间绑定
→ insert-shots.plan.json → 用户交给 Claude Code
→ P01.mp4、P02.mp4… → Codex 验收并按 insertAt 剪入
→ 左下真人、转场、字幕、配乐和混音 → 预览与用户确认
```

```bash
node skills/koubo-remotion-director/scripts/validate-insert-shots-plan.mjs --input <plan.json>
node skills/koubo-remotion-director/scripts/export-insert-shots-plan.mjs --input <plan.json> --repo-root <project-root>
```

导出器仅写固定路径的一份 JSON，不覆盖已有文件，不调用模型。修订先读已有计划、保留版本记录再精准修改和复检，不能改期号掩盖同一期冲突。本期生成目录是交接目录，不建立第二套口播工程；已有素材入口可指向它，不能覆盖桌面同名项。

交回 `<shotId>.mp4`：1920×1080、30fps、画面时长等于 `duration`，建议放回同一期目录。全集仅作参考，不能代替逐镜文件。接片检查解码、规格/帧数、中文、节点时点、动作关系、读字停留、声音和避让区域；只返工失败镜头。当前规则更新不代表下一期已完成端到端验证。
