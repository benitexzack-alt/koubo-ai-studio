# 强标题真人科技封面 v3

> 来源：用户提供的五组抖音主页样本、v1 失败四宫格和本项目真实人物测试。
> 状态：单条封面实验合同；不能凭审美直接推导点击率，发布后仍需回填数据。

## 视觉判断

主要借鉴两类抽象机制：

- 深色商业科技封面：大标题、真人主角、主题物件和冷暖电影光形成三角构图；
- 高信息密度 AI 教学封面：大数字或核心词、两三个证据物件、缩略图下仍可读。

只借鉴信息层级、人物占比、场景叙事和色彩关系。不得复制样本人物、品牌、Logo、账号名、独特文案、界面截图或完整构图组合。

## 共享品牌 DNA

四个候选必须像同一个账号，先锁定以下内容，再做差异：

- 定位：兰州 AI 创业者，服务本地小微企业；
- 主色：墨蓝 `#07111F`、电蓝 `#246BFD`、青蓝 `#2FD4FF`、暖金 `#F5BE45`、白 `#F7FAFF`；
- 字体：`Noto Sans CJK SC Black` 或已核权的同等级真实重黑体，不用普通字体伪加粗；
- 人物：授权真实视频帧的透明抠像，脸、手和衣服不进入生成模型；
- 光线：暖色人物主光 + 青蓝外侧轮廓光；
- 信息顺序：主标题 → 真人脸 → 一个主题证据组；
- 栏目：小号文字 `兰州 · 本地AI落地`，不得使用抢标题的大胶囊；
- 最后一百五十像素不放主标题、候选编号和关键事实。

四张可以在明暗程度和强调色比例上变化，但不得拆成紫、绿、红、蓝四套无关账号风格。颜色不计入候选差异。

## 四个候选方向

### 1｜AI 接班工作台

- 标题位于左上，真人位于右下；
- 桌面只出现菜品照片、活动日历、评价纸条和一个抽象 AI 处理核心；
- 深墨蓝为主，暖金桌面光与青蓝轮廓光形成冷暖对比；
- 禁止假代码、假后台、金币和无意义网络线。

### 2｜蓝白任务交接

- 标题位于左上或上中，真人从右下穿出；
- 三个任务使用真实物件感，不使用空白 UI 卡套卡；
- 冰蓝白为主，仍只引用同一品牌色板；
- 禁止廉价黄绿渐变、人物缩成小头像和大片无意义留白。

### 3｜三件物证上桌

- 标题位于左上，真人位于左下，三件物证占右侧；
- 可程序化加入一个低透明度大数字 `3`，但不得让生成模型写数字；
- 三件物证必须在 `270×360` 缩略图中仍能区分；
- 禁止截图拼贴墙、密集小字和二十个图标。

### 4｜本地老板收工现场

- 真人位于左下，标题位于右上；
- 背景是原创、非真实客户的门店工作台，三个经营物件自然存在；
- 暖色门店光与冷蓝 AI 光在人物附近交汇；
- 禁止虚构兰州地标、真实客户门店、假评论和假后台。

## 候选差异

四张围绕同一主题，但在以下四项中任意两张至少三项不同：

1. 标题角度；
2. 真实人物姿态；
3. 构图重心；
4. 主题证据物或场景叙事。

颜色不算差异。不得只换色、换标题近义词或微调裁切。

## 人物生产规则

1. 从授权真实视频选择清晰、自然、无明显拖影的帧。
2. 使用非生成式人物分割生成透明 PNG。
3. 人物只允许裁切、等比缩放、位置调整、肤色校正、透明蒙版、外侧轮廓光和阴影。
4. 不得换脸、补手、改变表情、改变衣服或把人物再次交给模型统一风格。
5. 正式候选不得使用原视频矩形窗口、圆角视频窗或连椅背一起铺满画面。

## 背景生产规则

- 正式候选背景必须标记为 `readiness=final`；
- 背景只生成无人物、无文字、无 Logo、无品牌界面、无水印的原创场景；
- 每张背景必须围绕当期语义物件单独生成；
- 代码渐变、光路、空框和几何节点只能用于 `layout-proof`，不得进入用户选择四宫格；
- 生图失败时停止在版式证明阶段，不能用占位背景继续交付。

## 文案与排版

- 主标题优先 8–16 个中文字符，2–3 行；
- 每行优先 4–8 个中文字符宽；
- 只突出一个最大词组，最多两种强调色；
- 黑底使用白、暖金、电蓝，避免粗重黑描边；
- 明亮底使用墨蓝、电蓝和暖金，保证局部对比；
- 标题不得压脸、压手或落入底部平台遮挡区；
- 不使用未经证实的排名、财富、涨粉、获客、销量、效率和节省时间主张。

## 审美硬失败

任一项出现即退回，不进入评分：

- 原视频矩形窗口感；
- 代码占位背景或通用科技线条充当正式背景；
- 人物脸、头顶、下巴或关键手势明显截断；
- 人物边缘有大面积黑边、白边、椅背残片或透明破洞；
- 四张只靠颜色形成差异；
- 标题与人物脸重叠；
- 三秒内看不出主题；
- 出现样本人物、Logo、水印、品牌混淆、隐私或虚假主张。

## 独立视觉评分

每张满分 100：

- 原创转译参考机制：20；
- 真人融合与边缘质量：20；
- 构图层级与单一视觉中心：15；
- 背景/证据物与主题关系：15；
- 手机缩略图可读性：15；
- 色彩、光影与品牌一致性：10；
- 工艺完整度：5。

放行线：

- 单张总分不低于 82；
- 真人融合和参考转译均不低于 15/20；
- 构图、主题关系均不低于 11/15；
- 缩略图不低于 12/15；
- 四张平均分不低于 85；
- 整组品牌一致性不低于 85/100，结构差异不低于 80/100；
- 无任何审美硬失败。

生成者不得自行填写独立复核通过。复核者只接收参考样本、风格合同、单图、缩略图、灰度图和人物蒙版，不接收生成者的自我辩护。
