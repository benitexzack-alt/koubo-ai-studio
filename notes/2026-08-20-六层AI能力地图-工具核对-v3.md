## 已核实的公开边界

- Kimi 官方帮助中心目前区分文档与表格能力，可输出和编辑 Word、PDF、Excel 等办公文件。
- WorkBuddy 官方资料将其定位为全场景 AI 办公工作台，强调自然语言下达任务、自主拆解并交付可验收结果。
- 飞书官方资料显示多维表格具有表单、自动化、工作流和 AI 节点等能力。本稿口语仍保留用户确认的“飞书表格”，卡片小字可写“表格/多维表格”。
- Codex 官方帮助资料说明其可在本地读取、修改和运行代码；Claude Code 官方文档包含读取、编辑和命令工具权限。
- GitHub 官方文档可支持“克隆仓库”这一基础表达；本条不延伸为产品已经完成部署或维护。
