## 三、免费与实际成本

这批候选使用 HyperFrames。它将 HTML/CSS 与动画代码渲染为视频；Claude Code 负责制作代码。

- [HyperFrames 官方快速入门](https://hyperframes.heygen.com/quickstart)明确它免费开源，本地渲染不使用 HeyGen 点数；编码 Agent、可选托管、语音、头像及生成媒体服务可能有费用。
- [官方仓库](https://github.com/heygen-com/hyperframes)采用 Apache-2.0。框架许可不等于 Skillry 包或素材具有相同许可。
- Skillry 公开说明要求 Node.js 22 或更新版本、FFmpeg 与 HyperFrames；两个 CreatorMotion 候选写明 CLI 0.8.30 或兼容版本。本轮未检查本机环境或安装兼容性。
- [Claude 官方会员说明](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-or-max-plan)说明 Pro/Max 可用统一订阅进入 Claude Code，与聊天共用用量。通过 API Key 使用则按 API 计费。用户表示已有会员，但本轮未读取账号套餐、模型权限、剩余额度或实际付费设置。
- 人物后大字涉及抠像。[HyperFrames 官方说明](https://hyperframes.heygen.com/guides/remove-background)支持本地移除背景；首次下载模型和安装推理依赖，随后复用缓存。本地抠像不等于整个 Skill 的其他动作都已审查，也不证明本人素材的抠像质量。
- 网站免费不是免费再分发包。网站[条款](https://skillry.dev/zh/terms)将 Skill 包使用与商业作品创作区分，并限制包本身、安装地址或凭据的再分发。免费包取得后的具体许可仍待阅读。不能将网站示例画面直接当成本人素材。

建议试验的费用边界：现有会员登录、本地代码与渲染、使用已有或本地构造素材；不启用收费 API、云渲染、付费媒体或额外用量。若依赖这些才能完成，先报告缺口与代价。总成本仍包括本机时间、会员额度、返工与人工验收。

## 四、一次交导演包、逐镜交付是否成立

技术上成立。[HyperFrames 官方渲染说明](https://github.com/heygen-com/hyperframes/blob/main/skills/hyperframes-cli/references/preview-render.md)支持指定独立子合成文件输出 MP4。例如官方提供指定 `compositions/intro.html` 的导出方式。这证明逐段独立导出能力，不证明网站模板无需调整就能满足我们的导演要求。

建议的未来交接：

1. 整份已确认导演包作为一次输入，共享正文、事实锁、参考画风和统一规格。
2. 每镜保留一个认知目标、中文、物件、动作顺序、动作结果、时长和镜头对应关系。
3. 首帧提示词转换为“场景初态”：构图、层次、纸面、准确中文、物件位置、灯光与摄像机。代码场景第 0 帧可作构图确认图。
4. 图生视频词转换为“确定性动作时间线”：何时进入、移动、连接、翻折、落定，结果保持多久；文字与承载物件共用变换节点。
5. 先完成代表镜，再按同一风格扩展已确认的其他镜头；每镜独立交付视频、场景确认图、源码与运行说明，失败只返工对应镜头。
6. 拍前用原句文字锚点；真实口播回来后，再按实录重绑动作与实际入出点，不能把拍前估秒数当最终对时。

这比将整套图生视频提示词原样粘贴更可靠。旧词可保留为艺术参考，但代码生产需要明确对象和时间线。代码中文字、数量和关系可能更可控，这是基于编程模型的合理推断，本项目尚未实测。

## 六、反方决策结论

**决策题**：下一期是否让 Claude Code 利用免费代码动画能力，试验替换口播中的纸艺素材制作，以减少 RunningHub 额外生成费用？

- **已验证事实**：有多个免费局部动效候选；二轮找到完整动画案例及公开提示词，但未找到三个专属免费安装包。HyperFrames 支持本地视频与独立子合成导出；当前导演语义信息可转译。
- **硬约束**：不改事实/本人原句，不将说明画面当证据，不伪造旧生产合同通过；视觉质量及用户确认仍必需。只能使用有权使用的包、字体、图片、音乐与本人素材。
- **偏好**：减少额外现金支出，利用已有会员，整包输入并分段收到结果。
- **未知**：包内实际代码与许可、本机运行情况、会员额度、中文和动态质量、制作时间、返工次数，以及摄影级纸材质。
- **主要矛盾**：能否在降低额外支出的同时保持实际纸艺质量，而非有没有视频导出命令。

三个承重假设与证伪方法：

| 假设 | 最强支持 | 反对证据或失败可能 | 验证 |
|---|---|---|---|
| 逐镜交付可行 | 官方子合成导出，模板存在可编辑场次 | 通用模板场次不自动等于导演语义段 | 实际输出一个可独立播放、可定位、可局部返工的镜头 |
| 能保持纸艺质量 | 代码可建立分层、文字、透视与时间线 | 免费示例主要为平面图形和界面；未证明真实纸纤维、折叠遮挡、厚度与动作声 | 用户将正常速度代表镜与《超级个体》对照 |
| 总成本下降 | 免费框架、本地渲染、现有会员 | 限额、高难材质、反复改代码可能把支出转成耗时 | 记录本镜制作时间、会员用量、返工和额外收费，与同类旧镜比较 |

**失败预演**：最可能先得到很整齐的二维卡片，却达不到用户期望的立体纸艺；之后为补材质反复返工并消耗额度。第二种失败是免费模板默认加入旁白、广告结构或背景音乐，挤压真实口播。防止方法是先锁单镜认知目标、禁止额外文案，明确声音角色和费用边界，再看实际结果。

**建议（按用户纠正更新）**：整段动画替代试验优先参考二轮的剪纸皮影或折纸涂鸦场景，机制说明参考纸张风播客案例。免费清单只保留为局部动效。当前案例支持进一步试验代码路线，不能证明现成安装包或摄影级纸艺直接胜任。

**最小下一步（仅方案）**：下一期选一个已确认的“带字物件进入—连接或装配—结果落定”镜头，固定中文、物件与动作，采用用户认可的整段动画画风，交给 Claude Code 制作构图确认图和独立短动画。不同配色不再被计作三个动画版本。新增代价仅为该试验的环境准备、会员额度、本机渲染和观看时间，暂不调整全链。

**通过标准**：用户对照参考认可画风；中文逐字正确、字物同动；数量与因果结果不漂移；正常速度看得懂；独立视频能交付且保留源码；声音符合本镜需求；实际成本与返工可接受。机器只确认技术与对应内容事实，不代替看听。

**停止条件**：不得不调用收费服务；同一主要问题连续两次未解决时，停止继续返工，先调查根因并提交方案由用户选择；开始自动改正文、伪造演示或扩展整片流程；结果只剩廉价扁平图而被冒称达标纸艺。届时暂停扩张，保留旧路线和失败证据。

**翻案条件**：真实镜头达到视觉标准且成本降低，可扩大替换；如材质质量持续不足，代码动效用于步骤、对照与关系说明，复杂纸艺仍逐镜判断，不能把失败隐去。
