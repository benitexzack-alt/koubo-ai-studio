# 普通人学AI与AIGC漫剧入门｜整合口播提纲 v1

<!-- CONTENT_START -->

## 一、重新锁定这条内容的核心问题

**观众问题：**我想学AI，有人想用AI提升工作，也有人想在家做动漫、漫剧、AIGC内容，但不知道从哪里开始，更不知道要投入多少钱。

**整合后的核心判断：**学AI不能从工具清单开始，要从你想交付的结果开始。想提升工作，就先完成一项真实工作的小闭环；想做AIGC漫剧，就先用一个创意做出30—60秒可验收样片，再决定自己做、找工作室、组团队，还是拿项目去找平台和扶持。

**本条交付物：**两张入门路径卡。

- 工作型AI：真实任务 → 输入 → AI第一版 → 人工验收 → 错误记录。
- AIGC漫剧：创意 → 角色/分镜 → 30—60秒样片 → 反馈/成本记录 → 选择合作路径。

## 二、开头：同一个“想学AI”，其实有两种完全不同的入口

### 0—5秒：直接给答案

“如果你想学AI，先别问哪个工具最强，先问你到底想交付什么：是把工作做完，还是做出一段能看的动漫、漫剧样片。”

### 5—20秒：两个具体场景

- 第一种人：收藏了课程、工具和提示词，面对客户咨询、会议纪要、表格时还是不会开始。
- 第二种人：有一个动漫或漫剧创意，想在家自己做，但不知道一张图、一段视频、整条样片到底要烧多少钱。

### 20—35秒：明确这条不是工具推荐

这条先不讲谁最强，而是讲两件事：普通人怎么找到AI学习入口，以及想做AIGC漫剧的人，怎么控制第一次试错成本。

## 三、为什么现在值得学，但市场大不等于个人能直接赚钱

### 35—65秒：AI入口已经普及

沿用上一版数据：生成式人工智能用户规模、主要使用目的和企业AI应用方向。结论只落到一句：接触AI的人很多，但会问问题和能交付一项真实工作是两回事。

### 65—105秒：漫剧是一个真实市场，但要拆开看

使用四组数据：

1. 2025年上半年微短剧用户6.26亿；
2. 北京市广播电视局研究报告披露2025年中国微短剧全年产值约1000亿元、相关存续企业超过35万家；
3. 国家广电总局公布2025年全年网络动画片603部、6657集；
4. 行业协会提到已有AI漫剧传播案例，但同时指出人物变形、透视和稳定性仍是瓶颈。

**必须说清：**这些数据证明市场和供给存在，不证明个人做一部漫剧就能赚到钱，更不证明AI漫剧就是低门槛暴富赛道。

## 四、第一条入口：想用AI改善工作的人怎么开始

### 105—155秒：五个基础不先学代码

问题定义、任务拆解、资料边界、结果验收、错误复盘。

### 155—205秒：最小工作闭环

用客户咨询、会议纪要或内容初稿举例：原始输入 → AI第一版 → 人工检查 → 交付结果 → 记录错误。

### 205—225秒：什么时候再学工具

任务反复出现、标准逐渐稳定后，再学模板、Skill、Agent、自动化或代码。没有真实动作，先堆工具只是在增加学习负担。

## 五、第二条入口：想做AIGC动漫、漫剧的人怎么开始

### 225—275秒：先判断自己缺什么

- 有创意但不会做：需要工作室或执行团队；
- 懂导演、镜头、节奏或行业内容：可以自己掌握创意和判断，找技术与后期协作；
- 既没有创意验证，也没有时间和预算记录：先别做长篇，先学会做样片和算账。

### 275—330秒：先做30—60秒样片

最低交付不是“生成几张漂亮图片”，而是：一句话故事、角色设定、6—12个镜头、声音、剪辑和一个完整动作。

通过标准：观众看得懂、角色大体稳定、镜头能连续、声音能听清、成本和修改次数记得下来。

## 六、把成本说清楚：模型很便宜，成片不一定便宜

### 330—385秒：公开价格样本

按当前火山引擎即梦AI公开刊例价测算：图片约0.20元/张，视频约0.28元/生成秒；5秒生成片段约1.40元。

### 385—440秒：为什么一条5秒视频不等于1.40元成片

一次成功只是理想状态。角色一致性、动作、镜头、画面连续性往往需要多次生成。按“12个5秒镜头、每镜4次尝试、36张关键图”的示例，60秒样片模型调用理论值约75元；加上配音、音乐、剪辑、失败重做和人工时间，个人实际小样片预算可按100—500元做保守测算。

3分钟试播集按同一假设，模型调用理论值约223元；加上制作环节，可能进入300—2000元区间。强调这是演算，不是统一报价。

### 440—465秒：漏算的成本

时间、分镜、角色资产、后期、声音、版权、AI标识、审核、备案和返工，往往比单次生成费更容易超预算。

## 七、四种进入漫剧市场的方式

### 465—520秒：从轻到重

1. **在家自己做：**只做30—60秒样片，设置预算上限和停止条件。
2. **借助工作室：**买一条样片或小试播，合同写清镜头、修改、角色资产、版权、交付和返工。
3. **组小团队：**创意、导演/分镜、视觉资产、生成执行、剪辑声音、发布合规有人负责。
4. **找平台、扶持或资方：**准备故事、样片、受众、预算、权利证明、团队和发行计划；只有创意没有样片，通常很难让别人承担投入。

### 520—550秒：现实边界

微短剧公开传播需要按平台和监管要求完成许可或备案；AI生成图片、视频和虚拟场景还要做生成合成内容标识。扶持项目也往往要求机构、规划备案、样稿或样片，不是个人发一个想法就能拿钱。

## 八、结尾：普通人真正的入场顺序

### 550—590秒：收束为一条路径

先选结果，再做小样；先记录成本，再扩大投入；先验证创意和协作，再选择自己做、找工作室、组团队或找资方。

**单一行动引导：**评论区写下“我想做的内容 + 我能先拿多少预算做样片 + 我最缺创意、技术还是团队”，下一步才能判断你该学什么、找谁合作。

## 九、表达与合规提醒

- 数据只证明市场存在，不做收益承诺和爆款承诺。
- 成本必须标注“公开价格样本 + 假设演算”，不能说成行业统一报价。
- 不使用未授权动漫、小说、游戏、真人肖像、配音或音乐作为示例。
- AIGC内容发布前按平台要求主动声明并保留生成记录。
- 这条内容核心不是“漫剧很赚钱”，而是“普通人如何用小样片验证自己是否适合进入”。
