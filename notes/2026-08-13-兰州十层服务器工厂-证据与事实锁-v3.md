# 兰州十层服务器工厂：证据与事实锁 v3

> 任务：回答“兰州市中心为什么会出现一座十层服务器工厂”，为观众价值框架和后续口播建立事实边界。
> 当前阶段：只允许进入提纲，不代表正文已确认。

## 一、已核验事实

1. 创速空间·兰州市信创产业园位于兰州市城关区段家滩路，是公开报道所称的兰州市首个“工业上楼”项目。园区所在建筑为十层，总面积约两万平方米。
2. 该项目利用原甘肃光学仪器总厂的老厂房进行更新改造，不是新征一块郊区工业用地后建设的传统平面工厂。
3. 甘肃日报报道援引城关区工信部门解释：城关区受“两山夹一河”地形约束，可利用土地资源有限；当地以提高容积率、向上使用空间的方式承接工业项目。
4. 2025年7月的公开报道援引城关区工信部门口径称：园区约两万平方米、累计投入一点三亿元、已招引八家企业并布局五条智能产线，功能覆盖研发设计、生产制造、产品展示和人才培育。
5. 公开报道显示，园区内存在服务器等信创整机生产线，也存在芯片与整机适配合作或相关平台建设。此次用户提供的现场视频、照片和纪要能够证明参访时看到了服务器装配、前测、老化、复检、包装、入库等环节及海光生态讲解。
6. “工业上楼”不是所有制造业都适用。北京、武汉等地方政府公开规则把适合上楼的产业概括为低能耗、低排放、低噪音、低震动或“精密小轻”，并要求同时解决承重、垂直运输、消防、管线等条件。该规则用于解释一般机制，不直接替代兰州项目的专项验收结论。

## 二、带归因使用的事实

1. “产业链协同效率提升”“搬迁后成本降低”来自公开报道中的企业及记者观察，正文如使用必须保留归因，不写成已经独立审计的普遍结果。
2. “八家企业、五条产线、一点三亿元”来自城关区工信部门对媒体的公开介绍，可用于说明项目规模，不能自动推出八家企业均已规模化生产或五条产线均达到稳定产量。
3. 任何“年产五万台”“万余台服务器”“七十多万台终端”等数字只能表述为公开产能或企业口径，不等于实际产量、销量、订单或市场占有率。本选题不需要以这些数字作为钩子。
4. 海光芯片对标英伟达产品的“八成左右”属于现场特定口径，缺少完整型号、任务和软件环境，不进入本选题的核心论证。

## 三、分析判断

1. 这栋楼最值得讲的不是“兰州也有服务器”，而是一个土地受限的中心城区，怎样利用存量老厂房承接适合上楼的新型制造。
2. 服务器整机装配相较重型、高震动、高污染制造，更接近公开政策所说的“精密小轻”上楼型产业；这是跨地区政策与兰州现场相互印证后的解释，不是兰州主管部门对每一道工序的专项结论。
3. 把生产、适配、展示、培训等功能放在同一载体，理论上可以缩短企业之间的物理距离；现有证据只能证明这些功能和合作正在被组织，不能证明成熟产业集群已经形成。
4. 对普通观众最有价值的判断不是“这项目好不好”，而是分清三层：机器是否真实上楼，企业和上下游是否形成协同，本地人才、适配与服务能力是否持续留下。

## 四、禁止扩大

- 不把“项目建成、产线存在”写成“产业已经成熟”。
- 不把设计产能写成实际产量、销量或订单。
- 不把现场某一芯片对标口径写成国产芯片普遍性能。
- 不把园区内存在芯片企业或展示空间写成“芯片在兰州设计制造”。
- 不承诺该项目会给普通人带来岗位、订单、创业项目或投资收益。
- 不把其他城市的“工业上楼”政策参数冒充兰州项目的验收标准。
