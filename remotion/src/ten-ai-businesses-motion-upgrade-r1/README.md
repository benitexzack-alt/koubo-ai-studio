# 《十个AI生意》Remotion 动效升级候选 R1

这是原生 Remotion 的参考适配候选，不是 CreatorMotion 官方 HyperFrames 组件的原样移植，不是本期剪辑或成片。仅新增本目录，未改变旧 Shotcraft、活动制作档案、共享组件、原片、字幕、导演 JSON 或六条纸艺路线。

## 先看独立实验

在 `/Users/pc/Documents/口播/remotion` 运行：

```bash
npx remotion studio src/ten-ai-businesses-motion-upgrade-r1/index.tsx --port=3010
```

组成 ID：`TenAIBusinesses-MotionUpgrade-R1-WithSfx` 与 `TenAIBusinesses-MotionUpgrade-R1-NoSfx`。两个版本使用相同画面，只有动作音开关不同。第三个 `TenAIBusinesses-MotionUpgrade-R1-ProtectionGuide` 使用中性底显示保护区导读。1920×1080、30 fps、1440 帧（48 秒），每种效果 8 秒。若端口已占用，先检查实际进程，不关闭其他项目。

本轮不提供裸 `render` 命令，不绕过 `remotion.config.ts` 的现行受控渲染门禁。Studio 预览不代表正式出片。

## 可编辑接口与接入边界

`effects.tsx` 导出 `BurstStatement`、`ChapterStamp`、`SequentialList`、`OpposingLabels`、`PipelinePackage`、`AdditiveEquation`；文字、章序、阶段、结果和层位置都作为 props。每个组件透明背景，不含整片壳，可作为后续 `renderCustomScene` 或 `persistentOverlay` 的候选内容层。外部 `<Sequence>` 给出实录重绑后的入点，本地帧从 0 开始；不得把演示每 8 秒机械套进本期。

左上层默认范围 `(64,96,760,680)`，右边界 x=824，实验真人保护区从 x=880 起，字幕区从 y=870 起；实际人脸、手势、已有字幕、素材视窗和平台安全区仍须逐镜核对。默认背景使用主代理已核对的本期真人静帧 `public/motion-upgrade-r1/presenter-layout-reference.png`，仅验证字号和避脸，并明确标为“本期静帧布局试验，非实录同步”；另有中性底保护区导读。不绘制假主播、假录屏或假官方证据。背景淡纸色可读层仅用于本独立实验，透明组件不内置整片或人像。纸艺/AI 视频内不叠加这些效果。

十个章名取自用户原文名词，长标题按两行展示，不缩字号。演示及每个透明组件外层标记 `translate="no"` 与 `notranslate`，避免 Chrome 自动翻译把已确认词条改字。演示仅显示第六项，接口可选择 0—9；实际按本期实录章节单独触发。全文仍由原导演 Skill 拆解，本实验不改写稿件，不为 95%/89% 等待核事实制作图表。

## 音效与验收限制

`plan.ts` 为每个动作记录本地派生 WAV、明确帧、长度、增益和角色。开场使用短重音，其余区分章节扫入、条目点选、关系连接和收束确认；各场景前景音不重叠。声音角色明确区分“入场/显现”和“读稳”，不把入场声标为最终落定。

主代理已在 `public/motion-upgrade-r1/sfx/` 生成本期独立派生文件：48 kHz、双声道、16 bit，原共享 WAV 未改。源段截取分别为 hook 0/0.340 秒、confirm 0/0.160 秒、keyword 0/0.250 秒、sweep 0.433333/0.172667 秒、click 0.033333/0.300 秒、slide 0.066667/0.400 秒、connect 0.100/0.400 秒（起点/长度）。样本级 5 ms 首渐入与 30 ms 尾渐出之后，测得 hook 峰为 −14 dBFS，confirm/click 为 −20 dBFS，其余为 −18 dBFS；主峰距派生首样本为 0.16—1.15 帧，均不超过 2 帧。长度在组件按帧向上取整为 11/5/8/6/9/12/12 帧。

组件不再做两帧淡入，避免压掉最初 20 ms 的主瞬态，只压短尾；已峰归一化的文件统一 gain=1，不再把短确认音二次压低。上述峰、样本包络和时点只属于技术检查，不证明可感知响度或人声混音安全。实际听感、瞬态与动作贴合仍要试听，不得把帧 cue 存在当作可感知音效通过。

本期静帧已作为布局参考；人声、原片实际时间轴、真实屏幕素材和字幕均未绑定；不宣称人声混音、响度安全、手机扬声器可听见或视觉质量已验收。正式采用前必须正常速度看 A/B，并对照原片核查人物保护区和字卡读稳；纸艺可用原生动作音仍保留，不以这里的 WAV 替代或统一静音。
