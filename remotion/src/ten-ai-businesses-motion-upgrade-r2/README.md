# 三种真实口播动效 R2 独立实验

本目录唯一入口是 `index.tsx`。两项 Composition 为有动作音与无动作音，均保留相同真实口播原声，播放速度为1；所有画面视频静音，原声单独由 `base.mp4` 对应窗口读取。开场take无音轨，匹配的声音窗口为原片4.4–9.8秒；后两段为33–39.8秒与37–45秒。20.2秒由三个连续窗口组成，不循环、不延长末帧，不是全片剪辑或发布包。

| 动效 | 候选范围 | 保留的运动 | 本期适配 |
|---|---|---|---|
| 人物背后大标题 | 0–5.4秒 | 原片→大标题→同帧真实抠像前景；标题冲入、小幅回落、快速清题 | 采用5.4秒take，1730像素SVG字面；4.72秒开始清题，末尾仍是真人；本期近景不套原例1.4倍裁切 |
| 格子溶解 | 5.4–12.2秒，原片33–39.8秒 | 独立8×5格；二维中心向外展开；目的地章名短暂读稳；边缘反向返回连续真人 | 暗蓝细网格与金点章名，属于单独实验；与原例相同的1.15/1.60/3.45/3.56秒动作节点 |
| 前景工具卡 | 12.2–20.2秒，原片37–45秒 | 真实图像整张卡片侧入；透视、轻倾与阴影收稳；最后三卡均匀排列，持续保留真人 | 豆包工作/WorkBuddy/Codex按实录38.060/38.860/39.650秒候选锚点出现；30fps采用不早于锚点的32/56/80帧 |

工具图片是必需的真实栅格素材，缺图、缺字体、缺matte时直接报错，绝不生成伪界面、假图标或白底备用卡。产品图只指明所谈工具，不作为产品能力或商业效果证据。音效复用本期R1本地派生WAV，按标题、格子、整卡动作分别触发。

人脸保护区底部为745像素；工具卡顶部752像素、高度184像素，原图94像素、正文44像素；字幕保护区从956像素开始。本期原片没有烧录字幕，本候选不添加或改写字幕。舞台不显示内部编号、审核状态、文件名或实验说明。

底片与alpha前景共享相同原尺寸样式、寻帧起点、时长、速度，不接受静帧或矩形人像替代。本目录只检查这层技术约束；同帧来源、抠像边缘、实际遮挡效果和原声可感知混音须由素材回执与正常速度观看继续核对。

本目录不修改R1、共享V8、导演JSON、默认Root、正式渲染入口，不导出MP4，不登记为已采用版本。

技术检查（在 `remotion/` 执行）：

```sh
./node_modules/.bin/tsc -p src/ten-ai-businesses-motion-upgrade-r2/tsconfig.json
node src/ten-ai-businesses-motion-upgrade-r2/test-boundaries.mjs
node src/ten-ai-businesses-motion-upgrade-r2/check-assets.mjs
```

前两项检查纯帧运动与边界；第三项要求所有本地文件到齐并用ffprobe核对真实时长、尺寸、帧率及alpha声明。通过不代表视觉或听感已经人工验收。
