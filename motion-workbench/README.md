# 口播动效工作台

本机使用的122项动效浏览、收藏与每期选效入口。图片与视频直接从官方原站按需显示，付费源码留在原归档，不上传、不复制进本仓库。页面必须通过本机服务打开，不能直接双击 `dist/index.html` 使用。服务启动后，本机目录和已保存的选择不依赖互联网；官方图片与动态示例仍需联网。

## 打开

双击本目录的 `启动动效工作台.command`，启动服务并打开浏览器；也可以在口播项目根目录执行：

```sh
node motion-workbench/scripts/launch.mjs --open
```

浏览器地址为 `http://127.0.0.1:5188`。启动器复用已有本工作台进程；端口被其他程序占用时报告错误，不杀进程、不换端口。仅监听本机，不提供外网访问。关掉浏览器不会删除选择，也不会停止本机服务。运行日志与自有进程信息在 `.local/`。

本仓库只包含工作台代码，不包含付费素材包、授权目录、原站媒体、账号数据、期次内容、本机审查 JSON 或生成后的索引。首次使用须自行确认相关使用许可，并准备本人可使用的原包以及对应中文审查资料后生成索引；原包与审查文件的预期路径以 `scripts/build-catalog.mjs` 为准：

```sh
MOTION_LIBRARY_PATH="本机授权包目录" node motion-workbench/scripts/build-catalog.mjs --refresh --check-media
```

`--refresh` 会联网读取第三方网站；如需回退到本地页面缓存，可另设 `MOTION_PAGE_CACHE`。示例链接的访问、展示和资料使用均需使用者自行核对第三方现行条款；代码中出现链接不代表获得再分发授权。依赖 Node.js 22 以上；页面与本机服务无额外 npm 依赖。

## 每期怎样用

1. 建立本期，粘贴或导入确认文稿/实录字幕。只存原文，不自动改写。
2. 浏览图片与动态示例，收藏常用动效。查看动作及素材要求后加入本期。
3. 给每个选择写明原句、显示内容与备注。未拍摄时入出点留空，拍后再按实录填写。
4. 等“已保存”后导出本期JSON或Markdown，作为该期后期交接。通过备份/恢复保存完整工作台记录。
5. 后期完成后，填写项目 `edit/` 或 `outputs/` 内的候选视频相对路径及定位秒数，回看实际动作。人工观看确认单独记录；修改关键选择后旧确认自动失效。

原站示例用于选型，历史V9实片用于观察既有适配，都不自动进入本期。选择保存不等于实际制作；导出清单不代替正式生产回执、全片验收或发布授权。

## 交给Codex或Claude读取

工作台使用独立选择格式，不把CreatorMotion编号塞入Shotcraft注册表，也不改纸艺/像素/测绘图纸的既有插片协议。执行者先核对用户明确指定的期号，再通过 `scripts/selection.mjs` 读取同一份已保存选择；不默认使用最近创建或当前打开的一期。以下命令在口播项目根目录运行，第一条仅列出期号，第二条读取指定一期：

```sh
node motion-workbench/scripts/selection.mjs
node motion-workbench/scripts/selection.mjs --episode 本期编号
```

读取到的 `koubo-motion-selection/v1` 包含本期原句、效果原编号、识别性动作、素材要求、实际时点和参考地址。后期按现行V9流程重绑原声/字幕/保护区，优先兑现用户选择的动作；不能实现或缺素材时明确说明，不能静默换成普通字卡。

拍前收藏或选择记录的是视觉意图，正式入出点须在拍后绑定实录。本期选择不改变全局V9基准，也不替代现行Shotcraft全库匹配规则。实际采用仍要对应实现文件、输出区间与正常速度观看结果；本工作台不会自动生成、渲染或发布，也不承诺122项均已适配或每条都合适。入口规范见[当前V9基线](../knowledge/23-V9导演编排与动效采用基线.md)。

## 保存与恢复

- `.local/catalog.json`：本机生成的122项目录，来源和检查证据见 `catalog-evidence.json`。
- `.local/state.json`：全部本期记录与收藏，磁盘保存并保留版本。不是只存在浏览器里。
- `.local/backups/`：每次覆盖前的磁盘备份。
- `.local/examples.json`：可选历史实片示例，来源单独核对。
- 并发保存检查版本。冲突或磁盘错误时保留草稿，先备份再重新读取，不自动覆盖。浏览器另留未保存草稿供恢复，但正式记录以服务端磁盘保存成功为准。
- “备份/恢复”导出全部期次与收藏。恢复时补入缺失期次；同一期存在不同内容时停止并提示，不覆盖已有选择。
- 上述本机数据不进Git；迁移时单独保存 `.local/` 和原授权包。不要公开分享整个目录或付费原包。
