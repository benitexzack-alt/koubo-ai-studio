## 一、结论先行

参考片的核心不是“米黄色纸面、海军蓝结构、红色点缀”，而是一套完整的纸媒叙事系统：

1. 把旁白拆成可见的语义节点和关系；
2. 用 4—7 级顺序装配让关系逐步成立；
3. 每镜至少存在背景承托、主体机制、前景标注或关系层；
4. 解释镜通常有 5—7 个物件组，证据板可达到 12—20 个语义节点；
5. 顶视工作台、正视机械、低机位微缩、左右分屏、中心放射、横向谱系和证据网持续轮换；
6. 视觉落点、旁白重音、字幕和拟音高度同步；
7. 先确定完成态静帧，再让视频逐片装配并锁回该静帧。

现有 `koubo-paper-construct-v1` 把它错误压缩为“固定暖纸配色＋单一主物件居中＋一镜一个动作＋文本直接生成视频”。这个抽象同时低于参考片和 MiniMax 官方纸艺 / 纸拼贴 Skill 的最低流程，不能继续修补后沿用原版本。因此：

- `纸构推演 v1`：`RETIRE`，保留为失败回归证据，不再进入新任务；
- 通用 RunningHub、MiniMax-H3、2K、费用授权、任务恢复和 Remotion 媒体舞台：继续保留；
- 新方向：`纸媒叙事装配 v2`，状态为 `blocked-candidate`；
- 在“批准完成态静帧真实送入 H3”以及单条动态压力测试通过前，不得称为可用 Skill，不得批量生成，也不得接入口播正式生产。

### 5.1 用户边界

- 插片不使用真人表演、写实真人场景或真实业务现场；
- 允许匿名纸偶、抽象剪影、原创漫画格和有合法来源的半调剪影；
- 不生成可识别真人脸，不复制参考片中的照片、版式、标题、品牌或镜头顺序；
- 画面用途固定为 `illustration-only`，不能冒充真实界面、数据、客户、地点或业务证据；
- 精确中文由确定性后期合成，生成模型不得自行编造文字。

### 5.2 语义与分镜

- 一镜只讲一个知识节拍，但一个知识节拍允许 4—7 级顺序装配；
- 每镜必须写清：核心含义、情绪、动作动词、无文字视觉隐喻、3—6 个主要物件组、语义节点、声音含义和最终关系；
- 复杂解释镜目标为 5—6 个物件组、9—13 个节点、至少 3 层、至少 5 级动作；
- 单动作机械镜可以每次只演示一个动作，但整镜仍需输入、机制、输出和环境承托，不得只剩一个齿轮；
- 连续镜头必须轮换构图，禁止连续多个镜头固定俯拍、单物件、大留白。

### 5.3 视觉语法

- 核心融合：高级编辑式纸拼贴＋可触摸的纸艺定格装配；
- 强制签名：大色块纸面、半调或纸偶主体、暖白描边、柔和实体纸影、精致撕边、纸纤维、层叠纸缝、可见纸厚；
- 每镜至少背景承托、主体机制、前景标注 / 关系三层；纸雕舞台通常规划 4—7 层；
- 解释镜至少 3—6 个可分离大物件组，不能把“主物件数=1”当作风格；
- 色板由本镜情绪和批准静帧决定。暖米白、黑灰、海军蓝、珊瑚红和灰绿是系列锚点，不是全片固定比例；
- 允许在纸张拼贴、粘土、蓝晒、水墨、极简图形之间切换，但必须保持核心主体、色锚、构图锚和转场节拍连续。

### 5.4 动作与镜头

- 默认组装顺序：干净色场→背景结构→主体物件→关系线 / 次要物件→压平 / 回弹→最终构图锁定→至少 1 秒完成态；
- 动作是分段、触感、可读的定格动作，不使用泛泛漂浮、全局淡入、顺滑数字平移、液化、无因变形或混乱飞散；
- 镜头可使用固定、轻推、轻横移、微距、层间视差和匹配切，不再限制为固定或极慢推近；
- 视觉结果应在目标关键词前后 `±300ms` 落地；
- 拼贴音效默认保留：滑入、弹入、压平轻敲、摩擦、脆响；不默认添加 BGM、旁白或模型字幕。

## 六、不可绕过的生产顺序

```text
实录语义拆解
→ 3—5 个创意方向
→ 用户选择方向和时长
→ 制作 Brief、视觉节奏轨和分镜
→ 用户确认分镜
→ 1—3 张风格 / 机制预览
→ 每镜生成完成态静帧
→ 用户确认静帧
→ 记录静帧路径与 SHA-256
→ 适配层证明该静帧真实进入 H3 请求
→ 只生成一条 4—5 秒动态压力测试
→ 与参考片及批准静帧并排验收
→ 用户明确通过动态样片
→ 才允许报价和批量生成其余镜头
```

任何一步缺失，都只能标记 `blocked`，不能用费用确认代替视觉确认，也不能把“任务生成成功”写成“风格通过”。

## 七、机器红线与人工验收

### 7.1 机器红线

所有对比先缩放到同一 `320×180` 口径：

- 解码率 100%，时间戳单调，无丢帧；
- 未声明黑帧和纯白帧均为 0；
- 非声明停帧不得连续完全重复超过 0.2 秒；
- 正常镜头时长中位数 3—5 秒；快速蒙太奇可 0.7—2.5 秒；复杂装配镜可 8—14 秒；
- 全序列灰度熵中位数不得低于 6.5 bit；参考值 6.84；
- 全序列边缘强度中位数不得低于 5.8；参考值 7.42；
- 已有规则仍是至少 90% 主边界在 `±100ms` 内达到全片音频瞬变 P75，至少 70% 达到 P90；锁定算法下参考片为 88% / 72%，因此参考审计本身在该门上失败并保持 `blocked`，不为了让参考片通过而下调 90%；
- 计划内中文标签 OCR 与文本清单 100% 一致，无乱码、伪字、随机英文；
- 批准完成态静帧的路径、SHA-256、实际请求图像字段和请求回执必须一致；只有提示词直接失败；
- 每条生成源片至少保留 1 秒完成态；
- 联系表、首尾帧、视频哈希、请求回执和动态 QA 缺一项，不得进入正式渲染。

灰度熵和边缘强度只负责筛掉明显低于参考的信息密度，不能代替人工审美。

### 7.2 人工验收

- 静音观看能否理解当前旁白核心含义；
- 材质是否真能区分纸张、瓦楞纸、粘土、蓝晒、水墨，而不是统一塑料 CGI；
- 前中后景是否有真实遮挡、纸厚和接触阴影；
- 物件、关系和动作链是否完整，有无无因生物、变形、错装；
- 构图是否随内容变化，同时保留统一视觉锚点；
- 画内中文在正常播放速度下是否可读；
- 与参考片并排播放时，信息密度、层级、动作链和完成度是否处在同一维度；
- 用户是否明确通过动态样片。机器绿灯、下载成功和成片渲染都不等于用户验收。

## 九、新候选的晋级测试

只做两种压力测试，不再直接生成整条口播：

1. **复杂解释镜**：对标 S06 / S08；至少 5—6 物件组、9—13 节点、三层、5 级顺序装配；
2. **单动作机械镜**：对标 S20；批准完成态图真实送入 H3，每次只完成一个动作，输入、机制和胶片结果逐项对应。

任一测试出现以下情况，立即失败：

- 绕过批准静帧或哈希门；
- 退化为单物件居中、固定俯拍、大留白；
- 节点、关系、中文或字幕错误；
- 纸媒材料不可辨；
- 动作链缺级、无因变形或错误装配；
- 联系表、并排动态复核或用户验收不通过。

同一硬失败经过一次受控修订仍复现，则移除该候选，不得继续靠堆形容词或整条批量生成碰运气。
