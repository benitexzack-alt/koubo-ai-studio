# 选题脚本与风格规范

## 零、内容总纲（2026-07-14 已确认）

### 1. 真实目标

账号不是用来证明“我懂 AI”，而是让一个具体的人看完后发生一种可观察变化：

- 少踩一个坑；
- 做对一个判断；
- 拿走一个工具；
- 完成一个动作；
- 看见一个经过验证的结果或失败。

一条视频如果只能让观众知道“AI 很重要、要落地、要从小事开始”，但不能改变下一步行动，不进入拍摄。

### 2. 当前主要矛盾

当前短板不是表达能力。用户能讲、敢讲、能把复杂内容说出来；当前主要矛盾是：

```text
强表达能力
vs
一线真实材料、案例证据、信息增量和可交付物不足
```

账号真正优势不是“什么都能讲”，而是把复杂方法翻译成本地老板听得懂、看得见、拿去能试的样品，并用真实企业视角说明适用条件和风险。

### 3. 内容价值工作模型

```text
内容价值 = 问题相关性 × 信息增量 × 可执行性 × 可信度 ÷ 理解成本
```

这是内部选题工作模型，不是抖音算法公式，必须用真实发布数据继续校正。

- 停留：观众是否立刻认出“这在说我的问题”。
- 点赞：观点是否击中身份、情绪或价值判断。
- 收藏：是否有提示词、清单、模板、步骤、风险表等可重复使用的东西。
- 转发：是否能帮助另一个明确的人解决问题或做决定。
- 关注：观众是否相信后续还会持续得到同类价值。
- 有效咨询：观众是否相信账号真正理解问题，并具备继续解决的能力。

点赞和播放只能说明部分传播结果，不能单独证明内容有用，更不能证明业务有效。

### 4. 群众路线在内容中的执行

```text
评论、私信、一线客户问题、项目失败和真实数据
→ 找出反复出现的主要矛盾
→ 提炼一个可以验证的方法
→ 做成工具、样品、清单或现场演示
→ 回到观众和客户中验证
→ 根据使用反馈和发布数据修正
```

不得先想一个漂亮概念，再去找素材证明它。经典方法、同行经验和 AI 结论都只能作为假设，最终以当前用户和真实实践为准。

### 5. 学习与原创边界

执行“多学习、多拆解、多结构迁移”，不执行逐字、逐镜头或案例数字复制。

```text
拆注意机制
→ 找用户利益
→ 换成自己的真实对象
→ 加自己的证据或实验
→ 做一个新的交付物
→ 用自己的口吻重新表达
```

可以学习：钩子、反转、案例顺序、问题命名、工具交付方式和行动引导。不得照搬：完整文案、人物故事、画面资产、未核验金额、客户结果、身份背书和受保护的方法材料。

## 一、参考风格

参考方向：科技商业口播、AI 趋势、案例分析、强标题、强观点。

学习点：

- 选题带趋势感。
- 开头迅速给冲突或身份。
- 标题直指利益、机会或风险。
- 画面包装服务观点。

不学习：

- 不复制具体文案、封面资产、栏目名。
- 不制造夸张人设。
- 不用无证据的财富承诺。

## 二、账号语气

- 真实、直接、本地化。
- 少讲术语，多讲老板听得懂的结果。
- 不装专家，不装成功学导师。
- 允许讲试错，但必须给下一步。

一致口吻不等于重复内容。可以长期保持“真实、直接、本地化”，但每一条必须有新的问题、新的证据、新的工具或新的结论。

## 二点五、选题与脚本硬门禁

### 1. 开拍前十问

每条视频必须回答：

1. 具体服务谁，他此刻遇到的具体问题是什么？
2. 这条只新增哪一个主张，与最近六条相比新在哪里？
3. 观众能拿走什么：提示词、清单、模板、表格、演示、案例、步骤或风险表？
4. 哪个真实案例、现场演示、官方来源或项目记录支撑主张？
5. 哪些是事实、个人观点、合理推断和待验证假设？
6. 什么情况不适用，最容易误用在哪里？
7. 看完只做哪一个动作，用什么真实数据判断这条有没有价值？
8. 账号和人物当前处于调查、试验、结果、方法还是复制阶段，这条是否跳过了尚未取得的结果？
9. 现有证据准确证明了哪一句话，是否把“工具能运行”偷换成“能涨粉、获客、成交或复制”？
10. 陌生人测试：如果同样的话由一个没有人设和结果背书的陌生账号说，目标观众还会相信、收藏或关注吗？

企业方法类、工具类内容必须同时具备“一个主张 + 一个证据载体 + 一个可带走交付物”。缺少任意一项，不开拍。人物经历类至少交付一个可复用判断，不能只讲感受。

### 2. 账号阶段、证据匹配与陌生人三道门

#### 账号阶段门

内容只能讲到真实实践已经到达的阶段，不得用表达能力代替结果积累：

| 阶段 | 当前可以讲 | 当前不能冒充 |
|---|---|---|
| 调查 | 真实问题、观察、一线材料、未知项 | 已验证的方法 |
| 试验 | 输入、动作、输出、失败和边界 | 稳定效果 |
| 结果 | 连续发布数据、真实使用反馈、有效咨询 | 普遍规律 |
| 方法 | 多个样本中的共同机制、适用条件 | 可复制系统 |
| 复制 | 可重复结果、成本、失败条件和恢复办法 | 保证结果 |

粉丝数不是唯一门槛，真正门槛是主张与证据是否匹配。但只完成技术运行，不能直接跳到流量、获客、成交或规模化方法论。

#### 证据匹配门

主张的强度不得超过证据的强度：

- 程序能运行、知识点能生成，只能证明流程跑通，不能证明内容会涨粉或带来客户。
- 脚本、构建和机器质检通过，只能证明制作链路可交付，不能证明观众认为有用。
- 播放、点赞和粉丝变化只能说明部分传播结果，不能单独证明客户价值或商业结果。
- 真实使用反馈、有效咨询、持续复用和可核验成交，才分别支撑对应层级的用户价值或业务判断。

写稿前必须先写一句“当前证据只证明______”，再决定标题和结论。标题、钩子、正文和行动引导都不得超出这句话。

#### 陌生人测试

去掉作者姓名、身份和自我描述后，逐项检查：

1. 目标观众现在为什么要看？
2. 他能立刻拿走什么，并在什么场景使用？
3. 可信度来自现场证据，还是来自“我懂、我能、我正在做”的自我声明？

三项中任一项说不清，先删除方法论结论；可以改成真实调查或试验记录，也可以暂缓，不为了保持更新频率硬写完整口播。

### 3. 当前重复母题冻结清单

以下结论已经在现有内容中反复出现，暂时只能作为背景句，不能再单独做成一条视频：

- 老板用 AI 第一步不是买工具、软件或系统；
- 要从一个重复、高频、低风险的小动作开始；
- AI 要落地、要做闭环、要用结果验证；
- 企业要先完成基础数字化，再接 AI；
- 把能力标准化、流程化后再复制；
- “我在兰州做 AI 创业”的身份宣言。

只有新增真实案例、新工具、新数据、反例或结论变化时，才允许重新启用这些母题。仅更换标题、行业名、概念名或比喻，不算内容增量。

### 4. 口播默认结构

```text
具体痛点、结果或证据开场
→ 让观众看见问题发生在哪里
→ 只讲一个新机制
→ 展示案例、工具或现场结果
→ 交付可复制的一小步
→ 说明适用边界和风险
→ 给出一个行动
```

首几秒优先展示问题、结果、对比或证据，不用“今天聊聊”“AI 时代来了”等空引子。先做出工具和证据，再写听起来顺口的旁白。

### 5. 外部视频拆解模板

每条参考视频不只记录主题摘要，还要拆出：

- 它让哪类观众在什么场景下认出自己；
- 开头用什么冲突、结果、损失或反转获得停留；
- 提供了什么以前不知道的信息；
- 用什么案例、数字、演示或身份建立可信度；
- 观众为什么会点赞、收藏、转发、关注或咨询；
- 哪个结构可以迁移，哪个事实和表达禁止复制；
- 改成我们的内容后，新增的真实对象、证据和交付物分别是什么。

### 6. “一工具、一问题、一条演示”实验

优先验证以下内容单元：

```text
一个真实客户问题
→ 一个范围明确的工具或服务样品
→ 一个输入
→ 一个可展示的输出
→ 一条完整演示视频
```

工具只能承担标准化、低风险的入口步骤，不能假装替代完整专业服务。医疗、法律、金融等高风险判断不得用通用智能体直接给结论；界面炫酷不能替代结果可用。

## 二点六、抖音精选内容质量目标

通过事实、来源、查重、机制、观众距离和账号阶段硬门禁以后，再按 `15-抖音精选内容质量验收.md` 检查四项质量特征：

| 特征 | 本账号默认要求 | 文稿必须给出的证据 |
|---|---|---|
| 获得感 | 主目标 | 新信息、新机制或新工具，以及观众能带走的判断或动作 |
| 惊喜感 | 按题决定 | 有证据的新角度、新反差或新表达，不靠夸张标题 |
| 表达力 | 主目标 | 唯一主张、具体场景、清晰结构和准确边界 |
| 感染力 | 有真实经历时使用 | 真实冲突、选择、失败或感受，不虚构人物和情绪 |

固定顺序：

```text
先保证事实正确、对象完整、内容不重复
→ 再明确获得感与表达力
→ 再选择是否增强惊喜感或感染力
→ 最后才设计卡片、音效、封面和镜头
```

新稿必须使用 `schema_version: 2` 的内容门禁卡并填写 `douyin_quality`。机器校验只能证明质量目标、正文证据和验收方式已经登记，不能证明作品一定入选精选、获得流量或产生商业结果。

## 三、标题生成规则

标题只负责压缩已经成立的新主张，不能代替选题、证据和交付物。先通过“二点五”硬门禁，再从本条内容中提取标题，不保留跨选题复用的固定标题模板。

优先从四种真实信息中取标题：

- 一个观众原来不知道的问题：`一千张卡为什么不能简单堆在一起？`
- 一个经过证据校正的误解：`Token不是虚拟货币，它真正计量的是什么？`
- 一个能观察到的变化：`AI开始读懂那些从未被写成文字的世界`
- 一个有边界的判断：`这个展品很震撼，但它还证明不了商业结果`

标题验收：

1. 删掉展会名、模型名和城市名后，是否仍表达本条新主张；
2. 是否能由正文中的具体机制或证据兑现；
3. 是否避免复用冻结母题、身份宣言和泛化“跟普通人有什么关系”；
4. 是否没有把可能、方向、演示或单个案例写成已实现的普遍结果。

## 四、封面方向

- 人像为主体。
- 大标题 8-14 个字。
- 辅助词不超过 1 行。
- 高对比：黑/深蓝背景，白字，蓝或黄重点。
- 不堆太多信息。

## 五、字幕风格

- 简体中文。
- 语义分行。
- 每屏 1-2 行。
- 关键词用蓝/黄高亮。
- 字幕不遮脸。
- 先保证读得清，再考虑动效。

## 六、系列化与追更结构（待验证）

> 来源：`source-materials/口播方法参考/2026-07-11-连续剧式口播参考文案.txt`，属于 C 级创作者表达样本。
> 状态：内容策略实验，不是已验证的平台规律；连续三条实测并取得发布数据前，不得升级为默认规则。

### 1. 长期母问题

- 一个系列只服务一类明确受众和一个真实、长期、可拆分的问题。
- 母问题不是越大越好，必须与账号事业主线和当前可取得的证据相匹配。
- 当前可优先验证的母问题：`甘肃本地小微企业，怎样以较低成本把 AI 放进一个真实业务环节，并验证是否有效？`

### 2. 单集闭环

- 每一集必须独立有用，只交付一个结论、动作或阶段结果。
- 开头可以回扣上一集，但不能要求观众必须看过上一集才能理解本集。
- 本集必须兑现上一集承诺，并展示真实证据、进展、失败或适用边界。
- 结尾最多留下一个下一集要验证的具体问题；后续必须兑现，禁止用空悬念代替内容质量。

推荐递进结构：

```text
发现真实问题
→ 拆出一个可验证的小任务
→ 做最小方案
→ 展示结果或失败
→ 调整并复测
→ 给出阶段结论和边界
```

### 3. 人设连续性

- 连续性来自稳定价值观，不来自刻意表演剧情。
- 固定坚持：真实、本地化、未验证不说死、敢展示试错、用结果检验观点。
- 热点内容可以插入，但必须能回到账号主线，不能让栏目和人设反复漂移。

### 4. 验证门槛

- 先连续发布三条同一系列内容，每条记录上一集承诺、本集兑现证据和下一集问题。
- 对比最近同类型非系列内容的完播、主页访问、关注转化、追更意图评论和有效咨询。
- 三条只能判断方向，不能证明普遍规律；没有发布数据支持时，继续标记为“待验证”。

## 七、发布验证与纠偏

- 每条发布前写明本条首要行为目标：停留、收藏、转发、关注或有效咨询，只设一个首要目标。
- 发布后回填完播、点赞、收藏、转发、主页访问、关注、有效评论、有效私信和企业咨询；缺失数据标记为未取得，不写成 0。
- 工具类重点看收藏、实际使用反馈和有效私信；案例类重点看完播、主页访问和企业咨询；观点类重点看转发和有效讨论。
- 连续三条只能形成阶段判断，不能证明普遍规律。数据不支持时，优先修改问题、证据和交付物，不先增加包装、术语和自动化。
- 第一条样片阶段已经结束；历史身份宣言只作账号背景，不再作为当前默认选题。
