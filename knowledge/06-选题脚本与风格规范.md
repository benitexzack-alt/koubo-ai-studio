# 选题脚本与风格规范

## 一、参考风格

参考方向：科技商业口播、AI 趋势、案例分析、强标题、强观点。

学习点：

- 选题带趋势感。
- 开头迅速给冲突或身份。
- 标题直指利益、机会或风险。
- 画面包装服务观点。

不学习：

- 不复制具体文案、封面资产、栏目名。
- 不制造夸张人设。
- 不用无证据的财富承诺。

## 二、账号语气

- 真实、直接、本地化。
- 少讲术语，多讲老板听得懂的结果。
- 不装专家，不装成功学导师。
- 允许讲试错，但必须给下一步。

## 三、标题模板

账号宣言：

- `38岁，我在兰州做AI创业`
- `为什么我想帮甘肃老板用上AI`
- `AI不能只属于北上广深`

企业问题：

- `兰州小店，先别急着投流`
- `本地老板用AI，第一步不是买软件`
- `小微企业怎么低成本试AI`

OPC：

- `一个人在甘肃，能不能用AI创业`
- `OPC不是概念，是一套交付方式`
- `普通人做AI项目，先别做平台`

算力连接：

- `庆阳有算力，本地企业缺什么`
- `算力中心和小微企业之间，缺一个翻译层`

## 四、封面方向

- 人像为主体。
- 大标题 8-14 个字。
- 辅助词不超过 1 行。
- 高对比：黑/深蓝背景，白字，蓝或黄重点。
- 不堆太多信息。

## 五、字幕风格

- 简体中文。
- 语义分行。
- 每屏 1-2 行。
- 关键词用蓝/黄高亮。
- 字幕不遮脸。
- 先保证读得清，再考虑动效。

## 六、系列化与追更结构（待验证）

> 来源：`source-materials/口播方法参考/2026-07-11-连续剧式口播参考文案.txt`，属于 C 级创作者表达样本。
> 状态：内容策略实验，不是已验证的平台规律；连续三条实测并取得发布数据前，不得升级为默认规则。

### 1. 长期母问题

- 一个系列只服务一类明确受众和一个真实、长期、可拆分的问题。
- 母问题不是越大越好，必须与账号事业主线和当前可取得的证据相匹配。
- 当前可优先验证的母问题：`甘肃本地小微企业，怎样以较低成本把 AI 放进一个真实业务环节，并验证是否有效？`

### 2. 单集闭环

- 每一集必须独立有用，只交付一个结论、动作或阶段结果。
- 开头可以回扣上一集，但不能要求观众必须看过上一集才能理解本集。
- 本集必须兑现上一集承诺，并展示真实证据、进展、失败或适用边界。
- 结尾最多留下一个下一集要验证的具体问题；后续必须兑现，禁止用空悬念代替内容质量。

推荐递进结构：

```text
发现真实问题
→ 拆出一个可验证的小任务
→ 做最小方案
→ 展示结果或失败
→ 调整并复测
→ 给出阶段结论和边界
```

### 3. 人设连续性

- 连续性来自稳定价值观，不来自刻意表演剧情。
- 固定坚持：真实、本地化、未验证不说死、敢展示试错、用结果检验观点。
- 热点内容可以插入，但必须能回到账号主线，不能让栏目和人设反复漂移。

### 4. 验证门槛

- 先连续发布三条同一系列内容，每条记录上一集承诺、本集兑现证据和下一集问题。
- 对比最近同类型非系列内容的完播、主页访问、关注转化、追更意图评论和有效咨询。
- 三条只能判断方向，不能证明普遍规律；没有发布数据支持时，继续标记为“待验证”。

## 七、第一条样片建议

标题：

```text
38岁，我在兰州做AI创业
```

副标题：

```text
服务甘肃小微企业，把AI落到地上
```

目标：

- 建立身份。
- 说明服务对象。
- 说明账号会讲什么。
- 吸引本地企业和本地创业者关注。
