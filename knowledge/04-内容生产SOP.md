# 内容生产 SOP

## 一、选题阶段

每条内容先填写：

```markdown
- 主题：
- 服务对象：
- 观众痛点：
- 这条视频只讲一个结论：
- 已验证事实：
- 待验证假设：
- 不能说的内容：
- 行动引导：
```

## 二、脚本结构

默认结构：

```text
3 秒钩子
→ 具体问题
→ 本地化观察或个人经历
→ AI 解决路径
→ 可验证的一小步
→ 单一行动引导
```

账号宣言类可用：

```text
我是谁
→ 为什么现在做这个账号
→ 服务谁
→ 以后讲什么
→ 为什么值得关注
```

企业服务类可用：

```text
本地老板常见问题
→ 过去做法为什么低效
→ AI 能先改哪一步
→ 最小落地方案
→ 需要什么资料
→ 私信/咨询引导
```

## 三、拍摄建议

- 一条视频只讲一个主题。
- 保持口语化，不背 PPT。
- 先录完整表达，不追求一次完美。
- 重要句子前后留 0.5-1 秒空白，方便剪辑。
- 尽量避免背景音乐直接录进原片。

## 四、后期流程

1. 复制原片到 `source/`。
2. `ffprobe` 技术检查。
3. 抽帧检查构图和画面问题。
4. 提取音频并转写。
5. 根据逐字稿做内容诊断。
6. 出剪辑策略，等确认。
7. 粗剪和响度处理。
8. 字幕、标题、信息卡和封面。
9. 导出预览。
10. 技术质检和人工确认。
11. 导出正式成片。
12. 记录发布数据。

## 五、发布后复盘

每条视频发布后记录：

- 发布时间和平台。
- 标题和封面。
- 完播率。
- 点赞、评论、收藏、转发。
- 有效私信数量。
- 是否带来企业咨询。
- 哪句话或哪个画面引发反馈。
- 下一条保留什么、删除什么、验证什么。
