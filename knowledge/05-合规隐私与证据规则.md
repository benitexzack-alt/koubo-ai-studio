# 合规隐私与证据规则

## 一、证据分层

- 已验证事实：有原件、官方来源、真实项目记录或端到端测试。
- 合理推断：基于现有事实推导，但未被真实结果验证。
- 未确认事项：用户陈述、计划、市场假设、待核验数据。
- 禁止公开：隐私、密钥、敏感合同、金融风险信息、未经授权客户信息。

公开口播必须优先使用已验证事实。合理推断要用“可能、我判断、我正在验证”等表达。

## 二、行业和政策数据

涉及以下内容必须重新查证：

- AI 用户规模。
- 甘肃企业数量。
- 庆阳算力规模。
- 国家政策、清朗行动、AI+制造。
- 平台规则。
- 行业收费、转化率、市场规模。

优先使用：中国政府网、国家发改委、国家数据局、工信部、网信办、甘肃省政府、人民日报、新华社、CNNIC、企业官方材料。

## 三、业务承诺边界

禁止承诺：

- 保证获客。
- 保证涨粉。
- 保证成交。
- 保证政府补贴。
- 保证接入算力中心。
- 保证培训后赚钱。

允许表达：

- “我们先做一个可验证的小闭环。”
- “用数据看有没有效果。”
- “从获客、内容、客服、销售中的一个环节先试。”
- “跑通后再复制。”

## 四、密钥和 API

- API Key 只存本机 `.env` 或环境变量。
- `.env` 不上传、不提交、不截图。
- 终端不回显完整密钥。
- 前端不暴露境外 API。
- 生图、转写、LLM API 默认视为外部服务，使用前说明上传内容和用途。

## 五、个人隐私

视频和脚本不得出现：

- 身份证、证书编号、住址、银行卡、合同细节。
- 未经授权的客户姓名、公司内部数据、聊天截图。
- 债务、流水、借贷等敏感细节。
- 家人、合作伙伴隐私。

## 六、AI 生成标识

如视频中出现 AI 生成图像、明显 AI 改写、AI 合成素材，应按平台规则进行适当标识。

## 七、反夸大清单

发布前搜索以下风险词：

- 第一、唯一、首家、领先、保证、必赚、躺赚、稳赚、国家认证、官方合作、政府背书、内部渠道。

没有证据时删除或改成保守表达。
