来源：AI降本这一期 V9 成片（5分28秒）复盘 + 会员 Skill 站 `bs-hyperframes-technical-drawing-promo` 的视觉语法。
效果截图：同目录 `A_tech.png`（推荐），另有 B/C/D 三个对比，见 `四种风格对比.jpg`。

> 本方案只是给 Codex 的修改提案，仓库还没改。下一期《国务院 AI 就业》用它试。

---

## 0. 一句话

一期只用一种主风格。凡是讲**数字、算账、拆解、政策条款**的插片，默认用新风格 `drafting`（测绘图纸风）：深色底，每句话、每个数字都放进选框、斜线阴影框、落线和尺寸线里，看起来像“量出来的”，不像“喊出来的”。纸艺只留给有实物场景的镜头，像素只留给打比方、游戏化的段落。

## 1. 为什么换

- 这一期我们自己的内容大量是**数字和算账**（1万件 × (100−50) − 15万 = 35万）。纸艺台面上的数字签字小、物件抽象，手机上读不清。图纸风天生就是给数字用的。
- 真人背景是**深色办公室加暖金色**，图纸风的近黑底加琥珀色点缀和它是同一个色温。纸艺米色和像素蓝天跟它一切就跳。
- 这个风格有一条硬规则叫“屏幕上每个数字都必须有出处”，正好对上我们已经在做的事实核验（老干妈人数口径这类）。
- 下一期是国务院文件解读。“把原文条款框起来、逐条标注”就是图纸风最擅长的版式。

## 2. 视觉规范（写进 `references/drafting-style.v1.json`）

| 项 | 值 |
|---|---|
| 底色 | `#0b0d10`，近黑，不能用纯 `#000` |
| 墨色 / 次墨 / 线色 | `#d9d9dc` / `#8e8e94` / `#2c2d30` |
| 强调色 | 琥珀 `#f2b544`，**只给结论数字和结果框**，每镜一处 |
| 标题字 | Noto Serif SC 900，72–96px，带 ±1.2px 红青错位（只加在标题上） |
| 正文 / 数字 | Noto Sans SC 700，数字 64–110px，最小可读字号 40px（手机） |
| 英文与编号标注 | JetBrains Mono 500，大写，字距 3px，16–20px，只当装饰性读数，不承载必须看懂的信息 |
| 选框 | 1px `rgba(255,255,255,.22)`，四角柄 13px（次级 7px） |
| 斜线阴影 | 132°，线宽 1.5px；小框用密 30px，大框用疏 56px |
| 落线 / 尺寸线 | 2×95px 从上往下长出 / 40×2px 从一端伸出 |
| 标尺、对位标 | 顶部和左侧各一条标尺（26px 一格，每 4 格一个大刻度）；对位标 13px 方块加十字 |
| 背景暗柱 | 30px 宽，间距 82px，`#101215` |
| 调色 | 全片统一一层：每 3px 一条 18% 扫描线，78% 暗角。不能每镜单独调 |

规范只定一次，所有镜头共用，不允许某一镜自己发明新构件。

## 3. 动作语法

- 选框是**画出来**的（裁切展开），不是淡入；角柄在框画完后错 2 帧落下，之后不动。
- 落线从上往下长，尺寸线从一端伸出，背景暗柱只在开头升起一次。
- 斜线阴影**永远不动**（一动就像画面撕裂）。
- 数字用滚动计数到终值，计数时长不超过 0.6 秒。
- 全片只用一次反色闪（2 帧），留给最重要的那个转折。
- 没有呼吸、漂浮、脉冲。镜头觉得空了，就加一条测量（尺寸线、读数），不要加动效。
- 同一版式停留超过 8 秒，必须有一次构图变化：推近到某个框、横移到下一组，或者把上一组收成一行摘要。

## 4. 六种版式（`shot.layout`）

| layout | 用在 | 结构 |
|---|---|---|
| `ledger3` | 算账 | 三个阴影框（因子）→ 落线到基线 → 算式一行 → 琥珀结果框 |
| `compare2` | 对比（用AI/不用AI、以前/现在） | 左右两个选框，中间一条尺寸线标出差值 |
| `flow` | 流程、因果链 | 节点框依次画出，用落线和横线串起来，当前节点亮 |
| `clause` | 政策原文、新闻原句 | 原文放进大选框，关键词逐个被小框选中，右侧拉出标注 |
| `readout` | 单个关键数据 | 仪表式读数：标签、实时指示、两个带方向的数字 |
| `stack` | 清单（三件事、新职业列表） | 编号阴影条逐条落下，最多同时 4 条 |

## 5. 版面安全区（三种风格通用，写进 `layoutContract`）

按这期成片实测：

- 真人小窗：x 64–464，y 620–845（左下）
- 字幕带：y 900–1060
- 插片内容区：x 520–1860，y 60–860。左边 64–464 这一列只放标题和章节标，不放关键数字。

## 6. `insert-shots.plan.json` 字段改动

兼容现有字段（`shotId`、`duration`、`style`、`nodes[{label, enterSec}]`），新增：

```jsonc
{
  "episode": { "primaryStyle": "drafting", "secondaryStyle": "paper" },   // 一期最多两种
  "shots": [{
    "shotId": "P04",
    "style": "drafting",              // paper | pixel | drafting
    "layout": "ledger3",              // 见第 4 节
    "assumption": true,               // true 时右上角固定显示「假设」
    "nodes": [
      { "label": "销量", "value": "1万件", "kind": "facet",  "enterSec": 0.6 },
      { "label": "单件毛利", "value": "100−50", "kind": "facet", "enterSec": 2.1 },
      { "label": "AI维护年费", "value": "−15万", "kind": "facet", "enterSec": 3.4 },
      { "label": "年利润", "value": "35万元", "kind": "result", "enterSec": 5.0,
        "source": "假设：1万件、成本80→50、年费15万" }
    ]
  }]
}
```

规则：

- `kind` 可选 `claim | facet | result | quote | readout`。
- 只要 `value` 里有数字，就**必须**带 `source`；是假设的写“假设：…”，是事实的写出处。没有 source 的数字由 Claude 渲染前拦下，不上屏。
- `clause` 版式的 `quote` 节点必须是原文逐字摘录，`source` 写文件名和条款号。
- `ledger3` 的三个 facet 字数要接近（差两个字以内），否则三个框不齐。

## 7. 路由规则（改 `visual-routing`）

- 讲数字、算账、比例、政策条款、清单 → `drafting`
- 有具体实物、场景、人物关系要“搭出来” → `paper`
- 打比方、游戏化、讽刺性的段落 → `pixel`（一期最多 1–2 镜）
- 一期里主风格的镜数要占插片的 70% 以上。

## 8. 顺便请 Codex 一起改的剪辑点（这一期看到的问题）

时间点按 V9 候选算。

1. **同一画面停太久**：「10家公司」从 0:28 到 1:10，同一张纸艺台面停了约 40 秒；「假设算账」从 1:28 到 2:01 约 33 秒；「省下来的钱去哪」从 2:46 到 3:10。建议拆成 2–3 镜，或每 6–8 秒换一次构图。
2. **主体太小，下半屏空着**：纸艺台面的前沿和深蓝底占了画面下方 40%，楼和物件只有屏幕高度的十分之一左右，真人小窗正好压在空台面上。主体应该放大到画面高度的 60% 左右。
3. **算账公式字太小**：两行算式加六个数字签同时在屏上，算式大约 22px，手机看不清。一次只亮一个数，最后只留结果。
4. **标注写错了**：纸艺镜左上角写着「AI生成·纸艺示意」，可纸艺是代码画的，不是 AI 生成。改成「示意动画」，只有 AI 情景片才标「AI生成」。
5. **AI情景片太小**：放在米色画框里只占约 60% 宽，四周留白大。建议全屏加缓推，真人小窗还放左下。
6. **画风切换太碎**：米色纸艺、蓝天像素、米色画框、深色办公室四套底色来回切。按第 7 节收成一主一辅。
7. **结尾没有收口**：最后停在「我是超哥，专注企业AI落地」的真人镜头上。可以加一张 2 秒的图纸风结尾卡（名字和一句话定位，放在选框里）。
8. **事实口径**：开头「600多人到48人」，你们自己的观看说明里也写了还缺一手人数证据，发布前要补上或改口径。
