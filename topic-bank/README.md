# 选题库

## 用途

这里管理 AI 时事、工具实测、本地企业观察和创业复盘候选选题。

选题不是按“热不热”决定，而是按六个维度打分：

- 新鲜度
- 本地相关性
- 可验证性
- 视觉化
- 商业线索
- 差异化

## 命令

```bash
# 在项目根目录执行
node tools/score-topics.mjs
```

输出：

- `topic-bank/topic-bank.scored.json`

## 推荐规则

- `82+`：适合 3-5 分钟主视频。
- `68-81`：适合 60-90 秒短口播。
- `56-67`：进入储备库。
- `<56`：暂不拍。

## 使用原则

热点只负责入口，真正要回答：

```text
这件事对兰州/甘肃本地企业有什么影响？
今天能做的一个小动作是什么？
有没有真实截图、实测或线下案例可以验证？
```
