# 超哥AI创业记 3:4 系列封面提示词母版

> 每期只替换方括号内容。其余人物、系列识别、信息密度、色彩和禁止项保持不变。

制作一张 **3:4 竖版、1080×1440 的抖音知识口播封面**，延续“超哥AI创业记”现有系列的统一视觉体系。

## 一、人物规则

使用我上传的**本条正式成片真人截图作为唯一人物素材**。

先从源截图中准确分离真人主体，移除源截图里已有的字幕、信息卡、软件图标、平台标志和栏目文字，再重新构图。只移除画面叠加层，不改变人物本身。

人物必须直接基于原截图进行真人合成，严格锁定：

- 真实五官
- 脸型
- 眼睛、鼻子、嘴型
- 发型
- 年龄感
- 肤色
- 衣服
- 麦克风及随身物品
- 原始表情
- 原始手势
- 身体比例和姿态

**禁止重新生成人脸、禁止换脸、禁止美颜重塑、禁止修改表情、禁止生成相似人物。**

只允许自然抠像、裁切、清晰度优化、轻微明暗调整和环境光融合。

人物通常位于**画面右侧或右下区域，占画面约 38%～45%**，保留半身近景及真实讲解状态；人物面部必须清晰，并与标题、结构图形成视觉互动。

## 二、系列固定视觉识别

画面左上角保留小型栏目识别：

**超哥AI创业记**

字号较小，白色或白色加亮青色，可配一条短青色线段、蓝色小标签或极简边框。不要让栏目名称抢主标题。

## 三、本期标题系统

**主标题：**

【填写本期核心标题】

**副标题：**

【填写本期辅助标题；没有则删除本项】

标题必须是整张封面的第一视觉中心。采用粗壮、紧凑、高对比中文无衬线字体。

使用三级文字结构：

1. 小栏目标签；
2. 核心主题，白色或白色加亮青色；
3. 最有冲突、判断或结果感的一句话，用高饱和暖黄色重点突出。

关键词允许略微放大。标题区主要位于左上至左中区域，不能遮挡人物面部和关键手势。标题必须保证在抖音主页九宫格小尺寸状态下仍能一眼读清。

禁止错别字、断句错误、随机小字、乱码和无意义英文。

## 四、本期知识结构

本期核心结构选择：**【三层结构 / 左右对照 / 上下对照 / 因果链 / 流程路径 / 分岔路线 / 能力阶梯 / 产业链 / 工作流 / 数据路径 / 问题→AI→交付结果 / 其他明确结构】**。

结构内容：

**【填写 3～6 个关键中文节点，每个 2～6 个字】**

不要只做“大标题＋人物＋一张科技背景”。结构图占画面约 20%～35%，放在标题下方、人物左侧或背景中景。使用半透明深蓝信息卡、细线、节点、简洁图标、箭头和连接路径表现逻辑。

信息卡要有空间层次和真实 UI 质感，但不能堆成 PPT 截图。只保留少量关键中文词。

## 五、核心视觉路径

加入一条克制的**暖金色或蓝金渐变路径线**，从【本期底层能力、AI 工具或数据节点】开始，经过【中间判断或流程】，最终落到【真实企业、用户、交付结果或责任】。

路径可以转折、上升、穿过层级并连接关键节点。线条要细、有方向感，不能变成廉价霓虹特效。

观众应一眼理解：**AI不是漂浮在空中的技术，而是在走向真实业务。**

## 六、背景层次

本期真实背景选择：**【中小企业办公室 / 商家经营现场 / 写字楼 / 数据中心 / 服务器机房 / 电脑工作台 / 产品研发现场 / AI工作流 / 兰州城市或企业现场 / 其他真实场景】**。

背景采用真实环境与抽象科技结构融合，形成：

**前景人物 → 中景知识结构 → 后景真实场景**

背景适度虚化和压暗，不能抢人物和标题。

## 七、固定色彩与光影

使用：

**深黑 / 深海军蓝 / 工业灰 / 冷青蓝 / 白色 / 少量暖黄色或暖金色**

深黑与深蓝负责背景，白色负责主体文字，冷青蓝负责 AI、数据和技术，暖黄色负责冲突点、商业价值、判断和结论。

整体为：**真实商业纪实摄影＋科技知识可视化＋电影级侧光。**

人物保持真人截图质感。人物边缘只允许极轻的环境轮廓光，禁止明显发光描边。背景暗、人物亮、标题最清晰。局部可使用蓝色信息光和暖金色反射，增强人物与环境融合。

整体要有深度、层次、判断感、商业感、AI产业感和本地创业者真实现场感。不要做成科幻电影海报、PPT 或廉价营销课广告。

## 八、信息阅读顺序

整张封面保持中高信息密度：

1. 第一眼看到标题；
2. 第二眼看到人物；
3. 第三眼看到本期逻辑结构；
4. 第四眼看到环境和细节。

不能退化成只有人物、大字和空背景，也不能塞满十几个小图标或几十行小字。

## 九、统一禁止项

禁止：

AI重新绘制人物、换脸、五官变化、脸型变化、皮肤塑料感、过度磨皮、修改手势、变形手指、生成其他主角人物、机器人头像、人形机器人、代码雨、宇宙背景、廉价赛博朋克、紫色霓虹、大面积紫色、金币、现金、豪车、收益数字、暴富暗示、成功保证、股票暴涨、真实平台Logo、二维码、联系方式、水印、随机数字、乱码、无意义英文、虚假企业后台、虚假收益截图、过度复杂小字、纯背景图式简单排版。

最终效果必须像同一个成熟科技商业知识博主账号长期运营形成的系列化栏目封面。放进“超哥AI创业记”现有主页九宫格中能够自然融入，同时让本期拥有独立、可读的知识结构视觉。
