# 01-口播包装模板说明

## 当前模板

- 工程位置：`/Users/pc/Documents/口播/remotion`
- 主视频：`AIBizTalk16x9`
- 封面：`CoverStill`
- 字幕来源：ElevenLabs 逐字时间戳转成 `@remotion/captions` 格式
- 主素材：`remotion/public/media/IMG_1911_proxy_16x9.mp4`

## 每条视频最小输入

1. 原始口播视频。
2. 转写 JSON，优先 ElevenLabs 逐字时间戳。
3. `visual-plan.json`：开始秒、结束秒、动效类型、标题、说明、素材来源、位置和避让规则。
4. 3-8 张真实截图或资料图，必须进入素材台账。
5. 封面主标题、副标题和底图。

## 风格原则

- 学结构，不复制对方素材、文案和账号包装。
- 画面优先真实截图、真实产品界面、真实企业场景。
- 字幕要服务理解，不遮挡脸和手势。
- 提示卡只在关键观点出现，避免全程堆满信息。
- 封面标题必须一眼说清利益点或冲突点。
- Remotion 只做局部动效片段，不替代粗剪和完整剪辑软件。
- 高频参数必须配置化：位置、颜色、字号、时间、避让区域。

## 当前限制

- 已安装项目专用 `ffmpeg-full`，路径为 `/opt/homebrew/opt/ffmpeg-full/bin/ffmpeg`。
- 字幕和提示卡优先由 Remotion 实现，FFmpeg 负责转码、校验和后续 ASS/滤镜兜底。
- 生图 / 图生图 API 已有配置占位和校验脚本，真实 Key 不进入项目文件。

## visual-plan

- 模板文件：`templates/03-visual-plan-template.json`
- 每条视频都先生成视觉方案，再进入 Remotion 组件制作。
- 第二次复用的动效进入配置，第三次复用必须模板化。

## OCR 标注

- 工具脚本：`tools/ocr-image.mjs`
- 用途：识别截图文字和坐标，生成可供 Remotion 使用的 `ocr-callout` 节点。
- 命令示例：

```bash
node tools/ocr-image.mjs 输入图片 输出.json --lang chi_sim+eng --psm 11
```
