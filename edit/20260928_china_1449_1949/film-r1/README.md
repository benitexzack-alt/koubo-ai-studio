# 山河五百年：1449—1949

依照已确认的“纸页＋水路”视觉方向制作的独立 Remotion 音乐历史短片候选工程。画面以 28 个连续事件镜头串联 1449 年土木之变至 1949 年 10 月 1 日中华人民共和国成立；六章合计 6497 帧，1920×1080、30fps，约 3 分 36.57 秒。切换强弱、事件文案与美术对应关系在 [`data/timeline.json`](data/timeline.json) 中；史实出处和视觉证据边界见 [`data/sources.md`](data/sources.md)。

## 本地渲染

项目使用 Remotion。安装与 `package.json` 相容的依赖，并使 `public/assets` 指向本目录 `assets`，再将用户提供的 `9月28日.mp3` 放在 `public/audio/music.mp3`。本机通过 `node_modules` 符号链接复用既有 Remotion 依赖；原音乐、成片、质量检查文件和临时 bundle 不纳入 Git。渲染时会检查所有 22 张美术资产和音乐是否齐备，缺失时不会生成有声正式候选。

```sh
npm run check
npm run stills -- c
npm run preview -- c
npm run render -- c
```

当前完整候选为 `exports/r6-b/山河五百年_1449-1949_完整成片_R6.mp4`。新制作入口为 `src/HistoryFilmR6.tsx` 与 `render-r6.mjs`；命令最后一个参数是本地版本号，必须使用尚未占用的版本号，避免覆盖已有结果。`preview` 只导出 25.2 秒有声检查样段，不等于全片。旧 `render.mjs` 和旧 R4/R5 保留为历史材料，不是本轮完整交付入口。如浏览器不在默认本机路径，可设置 `REMOTION_BROWSER_EXECUTABLE` 为现有 Chromium 可执行文件。

R6 使用逐帧驱动的连续纸页、卷轴、齿轮、帆船、轨道、会师双节点、渡江船阵和国旗展开；图片的远近层次、水面与镜头缓移构成景深。镜头边界按实测音乐落点微调，多年份事件分次揭示，末镜持续 5.4 秒。原曲从 0 秒直接合并，没有替换音乐、加速、调音量或按镜头重新拼接音轨。最新实际检验结果在 `exports/r6-b/质量检查.json`，导演执行表在 `data/director_R6.md`。

R6 b 实际检验：6497 帧完整解码成功、黑场 0，27 个场景切换均绑定实测拍帧；原曲对照的 10 个两秒窗口均为 0 样本偏移，无累积漂移。成片与原曲同为约 −11.1 LUFS、真峰 −1.4 dBFS。14.733—15.733 秒的低运动检测标记保留在报告中：实际解码 30 帧哈希均不同，重复帧 0，是首镜尾部运镜减速而非卡死，单窗复核不豁免别的窗口。机器检查完成，用户完整视听验收仍待确认。成片 SHA-256：`aac062486b8fc6f501fb122adab4bc428e7ea314b874eb28a54b1fe8ad36703e`。

历史 R4 的技术复测：6497 帧完整解码，未检出整帧黑场；原曲与工程内音乐 SHA-256 一致。R4 对原曲 10 处抽样的固定偏移约 9.4 毫秒，没有逐段漂移。该旧数据不能替代 R6 导出后的检查，也不等于一倍速听觉及审美验收。

## 使用边界

- 图像是原创历史艺术复原／示意，不是史料照片或当年纪录影像；画面中的建筑、服装和人物不单独构成某一史实的证据。
- 史实来源只支撑片中文字，不授权使用机构网页上的图片或视频。成片本身不是馆方授权或史料影像汇编。
- 配乐来自用户提供的文件。完成对外发布、商用或平台投放前，还需单独确认音乐权利和平台使用条件。
- 当前是本地候选片。机器检查只能验证帧数、解码、声画连续性等技术指标；一倍速完整观看、历史观感与审美验收须由用户确认。未获授权，不公开发布。
