# 两个工作流的投递方法

## 第一步：首帧生图任务

在能够访问本机文件的 Codex“首帧自动化”任务对话框中发送：

```text
请读取并严格执行这个首帧清单：
/Users/pc/Documents/口播/edit/generated-video/20260902_local_ai_services_paper-v3-r2/first-frame-prompts.v1.json

调用 koubo-paper-firstframe-producer。先生成 P01、P03、P07 三张样图，每镜独立生成，不得混入图生视频提示词，不得让模型生成可读中文，不得覆盖已有文件。完成逐图检查和联系表后停下，等我确认。
```

注意：把文件放进目录不会自动启动。必须在该 Codex 任务对话框中明确发送上面的指令。该任务需要能够读取 `/Users/pc/Documents/口播` 并装有 `koubo-paper-firstframe-producer`。

## 第二步：RunningHub 图生视频批量任务

只有首帧全部生成、中文写入和逐图验收完成后，才在能够控制浏览器的 Codex“简化 RunningHub 批量流程”任务中发送：

```text
请读取并校验这份图生视频清单：
/Users/pc/Documents/口播/edit/generated-video/20260902_local_ai_services_paper-v3-r2/runninghub-image-to-video-prompts.v1.json

调用 koubo-runninghub-video-batch，按 sceneId 一一绑定已验收首帧，配置 MiniMax H3、2K、清单时长和16:9画幅。先只配置一个校准节点并回读图片、提示词、模型和参数，停在生成按钮之前，不提交任务、不付费，等我确认。
```

注意：这句话应发给 Codex 的批量流程任务，不是发给 RunningHub 网站自己的 Agent 对话框。网站 Agent 不能稳定读取本机 JSON，而且可能出现自动提交或模型参数漂移。
