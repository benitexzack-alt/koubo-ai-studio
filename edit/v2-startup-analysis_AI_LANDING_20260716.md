# AI 落地现场纪实 V2 启动分析

## 真实目标

- 服务对象：甘肃本地小微企业、个体老板、创业者和 OPC 一人公司。
- 要改变的状态：把 44 分钟第一人称现场记录与两条第三人称素材，压缩为一条 8–12 分钟、能看懂服务过程的现场纪实粗剪。
- 可观测结果：主片清楚呈现“现场调查 → 业务流程拆解 → Codex / Vibe Coding 实操与安装 → 豆包 / GEO → 小闭环交付”，第三人称素材真实进入成片，片长、字幕、音画和隐私检查通过。

## 已验证事实

- 主原片时长约 44 分 23 秒，已有词级转写。
- 新增 `IMG_0128.MOV` 约 4.02 秒，新增 `IMG_0132.MOV` 约 14.41 秒，均为 3840×2160、约 60fps、HEVC 10bit、带现场音频。
- 两条新增素材拍到导播台、蓝幕、灯光、机位、监看画面和多人协作，可作为真实现场补充画面。
- 原始现场中存在电脑、手机、二维码、账号、联系人和定位元数据风险。

## 硬约束

- 不覆盖、不删除、不重命名原始素材。
- 真实画面承担主叙事，Remotion／信息卡只做章节、流程和 GEO 边界辅助。
- 不公开客户姓名、联系方式、账号、二维码、聊天、精确位置和未经授权的可识别人脸。
- GEO 不等于 SEO；只表述为增加被生成式 AI 理解、引用或提及的机会，不承诺推荐、曝光、咨询或成交。
- 删除模型版本、资费、代理、网络设置、登录、手机号、邮箱和原片明确说“不能展示”的内容。

## 待验证假设

- 两条第三人称素材在无原声覆盖、适度裁切和人物最小披露后，能显著增强现场感。
- 约 10–11 分钟是当前素材既能讲清过程、又不拖沓的合理长度。
- 中文短句字幕与少量章节标签足以支撑粗剪判断，复杂 V4 包装留到内容确认之后。

## 可删除项

- 旧版大面积 V4 卡片和全画面强模糊。
- 无关闲聊、等待、来电、安装空档、软件版本与套餐说明。
- 豆包现场生成的搜索量数字和任何无法核验的获客效果表达。
- 重复演示与不能推进问题链的长操作画面。

## 最小可验证方案

1. 重建 8–12 分钟 EDL。
2. 将两条第三人称素材各使用一次，覆盖开场和现场理解段落。
3. 先生成带中文字幕、局部隐私处理和少量章节标签的 V2 粗剪。
4. 做完整解码、时长／规格、黑场／静音、响度、字幕抽帧和隐私风险帧检查。

## 验收与回滚

- 机器验收：1920×1080、30fps、H.264/AAC；完整解码无错误；时长 8–12 分钟；无持续黑场和异常静音；抽帧中无明显隐私与字幕越界。
- 人工验收：用户完整观看并确认主线、节奏、人物和真实感后，再进入正式视觉包装。
- 回滚：保留 V1 与全部原始素材；V2 使用独立 EDL、工程目录和输出文件。
