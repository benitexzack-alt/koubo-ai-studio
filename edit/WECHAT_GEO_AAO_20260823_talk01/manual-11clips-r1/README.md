## 收片后的固定流程

1. 每段素材计算 SHA-256，检查规格、时长、画幅和流信息。
2. 完整解码，检查黑帧、长冻结、闪烁、乱码、水印、形变和风格漂移。
3. 以 1.0 倍正常速度逐段观看，确认动作与对应口播语义一致。
4. 通过的文件登记后进入 `03_已验收素材/`；原下载文件仍保持只读。
5. 按 `04_剪辑工程/剪辑方案模板.v1.json` 制作 1280×720 低清预览。
6. 用户完整观看低清预览并确认后，再输出 1920×1080 正式候选片。
7. 发布包补齐真人截图、主标题、两个备选标题、发布文案、话题和发布记录；公开发布仍需单独确认。
