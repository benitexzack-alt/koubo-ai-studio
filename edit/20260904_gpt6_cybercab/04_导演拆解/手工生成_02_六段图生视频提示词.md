# 六段图生视频提示词

与《手工生成_01_六段带字首帧提示词》一一配对。先拿到文字准确的首帧，再使用本文件。参数沿用已用过的 MiniMax H3 / 2K / 16:9；时长见各段。平台实际可选项以界面为准，本文件不代表已提交或产生费用。

全批预计42秒素材，不等于成片中必须铺满42秒。保持原生纸片动作声，不能生成旁白和额外字幕。剪辑时只按实录语义取用，不冻结末帧拖时长。

## P01 从问答到软件操作 / 7秒

```text
把上传首帧作为唯一视觉基准，生成7秒纸艺停格质感动画。镜头固定，保持画幅、光线、纸质材料、全部物件和四张纸牌身份。纸面文字“一问一答”“电脑”“浏览器”“业务软件”逐字保持，字与纸牌一起存在，不重写、不变形、不变成屏幕字幕。
按次序完成动作：先停留让人看清左右区别；左侧一张无字回答纸滑入对话托盘并停下；右侧珊瑚红任务纸沿实体轨道到纸电脑；再到浏览器窗口，窗口只做一次轻微机械展开；最后任务纸进入业务软件抽屉，抽屉轻轻合拢；结尾稳定停留。
左侧和右侧始终互不连接。四张文字牌保持静止正面可读，不翻转、不折叠文字，不增加物件或新文字。只有纸片滑动、卡槽进入和抽屉合拢的克制原生声音，无音乐、无人声、无夸张电子音。不是形状随机变形，而是一次从问答到软件操作的对照。
```

## P02 任务到交付 / 8秒

```text
上传首帧是唯一视觉基准，生成8秒真实纸艺停格质感动画。固定机位，保持五个工作站、三张资料纸、四张标签牌及全部纸质细节。纸面文字“业务任务”“操作软件”“排查问题”“交付结果”准确保持，文字牌静止清晰。
顺序动作：任务入口的珊瑚红纸片向操作台滑动；电脑纸框机械打开一次；资料架上原有的三张纸依次滑到轨道旁并对齐，不复制、不增加；整叠资料经过无字检查窗口，其中一张轻微错位纸被推齐；检查后的原有三张纸进入最后的交付盒；结尾停留展示交付盒已收到这叠资料。
必须先经过操作、收集和检查，再进入交付盒，不能开头就出现结果。所有运动是刚性滑移和无字部件展开，不折叠或重新生成文字牌，不生成勾号、印章、编号、额外中文。保留轻微纸张滑动、对齐与入盒声，无音乐、无旁白。
```

## P03 传统驾驶中的人 / 7秒

```text
以上传首帧为唯一基准，生成7秒纸艺停格质感动画，机位固定，保持驾驶员与四个职责物件。“人开车”“人判断”“人负责”“人决策”四张纸牌始终原样、静止、正面可读。
按次序让职责被看懂：纸驾驶员的手带动方向盘轻微转动；观察窗口中原有道路纸片短距离滑过；承托座椅的底座向卡槽轻压归位，强调人仍在中心承担职责；人物手边的分岔选择器拨向一条已有路线；全部动作停止，人物和四张牌一起完整保留。
不要移走驾驶员，不表现无人负责，不让方向盘消失，不添加机器人或品牌。动作幅度小，纸牌不旋转、文字不弯曲不重绘。仅有轻微纸轴转动、纸片滑动和卡槽落位声音，无音乐、无人声。
```

## P04 软件与现实两条路径 / 7秒

```text
以上传首帧为唯一视觉基准，生成7秒纸艺停格质感动画，固定镜头，保留上下两个独立平台及中间隔板。“软件系统”“商业工作”“现实世界”“执行身体”四张纸牌文字始终准确清晰，位置不动。
顺序展示两种路径：上层软件文件夹机械展开；上层无字任务纸沿上层纸轨道滑向工作托盘并归位；上层停住；下层原有道路门洞轻微打开；下层无品牌纸质小车沿原有短路前行一小段并停下；结尾同时保留上下两个独立场景。
上层不向下层发射光线，不穿过隔板，不用线缆连接电脑和汽车，不暗示该软件控制这辆车。不开新场景，不产生额外模型名称、AGI或成功结论。文字牌不翻折、不漂移、不重绘。保留克制的纸片、纸轮和纸门声音，无音乐、无旁白。
```

## P05 人的工作不能消失 / 7秒

```text
以上传首帧为唯一基准，生成7秒纸艺停格质感动画。固定镜头和人物位置，人物全程保留。“决策”“判断”“服务”“经营”四张实体纸牌原样保持，静止正面可读。
按顺序：后方重复任务轨道的原有无字纸片滑过一次；人物手边的选择拨杆轻轻转到一个位置；两块比较样板滑到并排位置；两把服务座椅相向靠近少许；经营记录册的空白内页展开一次，同时连接已有物件的棉线轻轻绷直，表示资源协调；所有物件稳定停留。
重复轨道不能替人物做选择，人物不能被机器替代或消失。不要增加钱币、收入数字、订单、成功章或新标签。纸牌本身不转动不变形，不改文字。保留轻微滑纸、拨杆、翻页声音，无背景音乐和人声。
```

## P06 四类服务工作 / 6秒

```text
以上传首帧为唯一视觉基准，生成6秒真实纸艺停格质感动画，机位固定，保留四种不同工作物件。四张纸牌“营销策划”“视觉设计”“SOP搭建”“数据复盘”原样保持，文字不重绘，纸牌不移动不翻折。
按次序：第一组方案夹的一张无字内页滑出少许；第二组两块原有色样滑到画板旁；第三组空白流程折页沿原有折痕展开；第四组记录册空白内页翻开，原有比较纸片并排对齐；四组同时稳定停留，表示四类工作都可被分别看见。
只展开无字物件，不把标签折成别的形状，不出现增长曲线、订单、金额、勾号、印章或任何收益保证。不是四个物件融成一个盒子。保留纸张滑移和折页展开的轻微原生声，无音乐、无旁白、无新增字幕。
```
