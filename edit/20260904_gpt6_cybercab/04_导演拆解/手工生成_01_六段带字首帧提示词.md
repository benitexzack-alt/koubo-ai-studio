# 六段带字首帧提示词

本期：GPT-6 与 Cybercab。每段代码框可独立使用，不需要另拼通用提示词。

这是用户手工生图用的候选提示词，不是自动化原图/OCR通过回执。旧两轮失败图保留，不需要继续自动试图。先看图中四组中文是否准确、是否各在自己的纸牌上，再用于图生视频。

图片仍放在桌面「口播素材 / 2026-09-04_GPT6与Cybercab / 05_首帧图片」，依次命名 P01.png 至 P06.png；视频放同一期「06_用户生成视频」。不需要另建项目。

## P01 从问答到软件操作

对应口播：不再单纯靠一问一答，能够操作电脑、浏览器、业务软件。后续视频建议7秒。

```text
生成一张16:9横版、真实微缩纸艺摄影风格的动画首帧。靛蓝纸质背景、暖白与工业灰卡纸主体，少量珊瑚红点缀。清楚呈现纸张纤维、厚卡纸切边、折痕、真实柔和侧光和接触阴影。构图有前景桌面、中景物件、后景立体纸板三层，画面完整，四周留余量，底部留出简洁空桌面供后期字幕使用。

主题是“从一问一答，到操作软件”。桌面分成两个不相连的区域：左侧是一个纸质对话收件托盘；右侧从左到右是纸电脑、纸浏览器窗口、纸质业务软件抽屉，三者之间有可滑动任务纸片的实体纸轨道。左右区域之间保留清晰空隙，不铺跨区轨道。右侧轨道入口放一枚珊瑚红无字任务纸片，尚未开始运行。

画面恰好四张独立的硬纸标签牌，每张使用大号清晰黑色中文印刷字，文字直接印在纸面上，与纸牌共同具有透视和阴影：
左侧对话托盘前，写“一问一答”；
右侧纸电脑前，写“电脑”；
右侧浏览器窗口前，写“浏览器”；
右侧业务软件抽屉前，写“业务软件”。
浏览器窗口和它前面的标签牌是两个不同物件，不能漏掉“浏览器”纸牌。四张牌全部朝向镜头，字号足够大，不能被遮挡。除此之外不添加其他文字，不画品牌Logo，不使用真实软件截图。不要扁平信息图，不要悬浮字幕，不要PPT，不要发光特效。所有物件完整入画。
```

## P02 任务到交付

对应口播：拆解目标、操作软件、搜集资料、排查问题、自我校对，最后交付结果。建议8秒。

```text
生成一张16:9横版、真实微缩纸艺摄影风格的动画首帧。靛蓝纸质后景，暖白与工业灰厚卡纸，少量灰绿和珊瑚红。可见纤维、折痕、层叠纸边和真实接触阴影。轻微俯视的三分之四视角，前景空桌面、中景工作台、后景纸板形成三层空间。所有工作站完整入画，底部留出简洁空桌面供后期字幕使用。

主题是“一项业务任务经过处理，最后交付”。桌面从左向右排列五个不同工作站，用一条实体纸轨道顺序连接：任务入口托盘、纸电脑操作台、资料收集架、检查窗口、交付收件盒。任务入口有一张珊瑚红无字任务卡。资料收集架上只有三张资料纸，分别为灰绿色、暖白色和工业灰色，纸面为空白。检查窗口是没有符号的方形纸框。最后的交付盒目前为空，不能提前装满结果。

恰好四张独立硬纸标签牌，使用清晰大号黑色中文，直接印在纸面上：
任务入口托盘前写“业务任务”；
纸电脑操作台前写“操作软件”；
检查窗口前写“排查问题”；
交付收件盒前写“交付结果”。
第三站资料收集架只展示三张资料纸，不放第五张标签牌。四张标签牌保持正面可读，不倾斜到难以识别，不相互遮挡。除此之外不添加其他文字、印章、勾叉、编号、装饰标记或Logo。不画笔筒和多余零件。不要扁平信息图、悬浮字幕或发光流水线，保持真实可制作的纸模型质感。
```

## P03 传统驾驶中的人

对应口播：人开车、人判断、人负责、人决策。这里讲的是传统驾驶角色，不是被剪掉的“没有人负责”。建议7秒。

```text
生成一张16:9横版、真实微缩纸艺摄影风格的动画首帧。靛蓝背景，暖白和工业灰纸模型，少量珊瑚红定位零件。纸张有真实纤维、厚度、折叠痕迹与柔和侧光。前景桌面、中景驾驶模型、后景道路纸板形成三层空间，完整入画，底部留简洁空桌面供后期字幕使用。

主题是“传统汽车以驾驶员为中心”。中间是一个无五官的暖白纸人，坐在简化驾驶座上，双手靠近实体纸方向盘。围绕同一个人安排四个不同物件：左前方纸方向盘、左后方观察道路的小窗口、人物正前方承托驾驶座的责任底座、右侧可以拨动的道路分岔选择器。它们都属于同一个驾驶员，不是四个驾驶员。

画面恰好四张独立硬纸标签牌，用大号清晰黑色中文直接印在纸上：
方向盘旁写“人开车”；
观察窗口旁写“人判断”；
承托驾驶座的底座前写“人负责”；
分岔选择器旁写“人决策”。
四张纸牌都朝向镜头，正面完整可读，与各自物件明显对应，不挡住驾驶员。不生成车型Logo，不画真实人物面孔，不生成其他文字或仪表盘数字。不要移除人，不表现无人承担责任，不用机器人头代替驾驶员。不要悬浮信息卡，保持真实纸模型摄影。
```

## P04 软件与现实两条路径

对应口播：软件系统内完成商业工作，与现实世界的执行身体。只作两类能力对照，不画GPT操控特斯拉，也不把示意图当作AGI已经实现的证明。建议7秒。

```text
生成一张16:9横版、真实微缩纸艺摄影风格的动画首帧。靛蓝纸质后景，暖白与工业灰厚卡纸主体，少量灰绿和珊瑚红任务纸片。柔和侧光，清楚的纸纤维、切边、接触阴影。三分之四轻俯视，前景空桌面、中景上下两层装置、后景立体纸板形成三层空间，底部给后期字幕留简洁空桌面。

主题是“软件中的工作与现实中的执行”。上下两个独立纸平台之间有完整的不透明隔板，不连接电线或轨道：上层左边是纸电脑与软件文件夹，右边是用于承接文件的工作托盘，两者用纸轨道连接；下层左边是代表真实场景的纸道路与门洞，右边是一辆没有品牌、没有字样的简化纸质小车。上下两层分别保留各自的珊瑚红无字任务纸片。

恰好四张独立硬纸标签牌，正面朝镜头，大号黑色中文直接印在纸面上：
上层纸电脑前写“软件系统”；
上层工作托盘前写“商业工作”；
下层道路前写“现实世界”；
下层纸质小车旁写“执行身体”。
四张牌完整清晰，互不遮挡。上下层不能互通，不能画出某个模型正在遥控汽车的关系。无真实品牌、无车型Logo，不增加“AGI”“成熟”“成功”等字样。不要科幻脑部图案，不要发光电路，不要扁平PPT，要像可以实际搭建的纸艺对照装置。
```

## P05 人的工作不能消失

对应口播：机器干重复的事，人做决策、判断、资源、服务、经营。四张牌表现其中四项，资源用连线连接已有物件，不漏掉其关系。建议7秒。

```text
生成一张16:9横版、真实微缩纸艺摄影风格的动画首帧。靛蓝后景，暖白与工业灰厚卡纸，少量灰绿和珊瑚红。纸纤维、层叠纸边、折痕清楚可见，真实柔和侧光和接触阴影。前景空桌面、中景人物工作台、后景独立纸轨道形成三层空间，完整入画，底部留出后期字幕空间。

主题是“重复工作与人的经营工作分开”。画面中心保留一个无五官的暖白纸人坐在工作台后，人物不能消失。围绕人物的桌面有四个不同工作物件：左侧选择拨杆、左中两块可并排比较的样板、右中面对面的两把服务座椅、右侧可翻开的经营记录册。细棉线连接四组物件，表示资源协调。后方另有一条独立小轨道，摆放几枚相同的无字纸片表示重复任务，与人物的决策桌分开。

恰好四张独立硬纸标签牌，大号黑色中文直接印在纸面上：
选择拨杆前写“决策”；
比较样板前写“判断”；
服务座椅前写“服务”；
经营记录册前写“经营”。
四张牌正面完整可读，不挡人物；棉线不再另配第五张文字牌。除了这四组文字不生成其他字、数字、印章、勾叉、Logo。不要钱币、现金或收入曲线，不暗示收益保证。不要悬浮信息卡或机器人替代人物，保持温和真实的纸艺模型摄影。
```

## 首帧交回检查

- 一图对应一镜，保留P01至P06编号；上面的标题只用于文件命名，不要额外印进画面。
- 四组纸面文字逐字准确，各自对应正确物件；缺字、错字、串牌先改图，不急着生成视频。
- 物件完整、字够大、纸牌不遮挡，字幕区有空间；不以几何位置百分比作为手工候选整批否决理由。
- 未生成其他收益承诺、品牌或不属于口播的结论。
- 交回图只是候选。动态图仍需检查字形稳定和动作语义，不能以静帧通过冒充视频通过。
