# 事实与发布风险锁

> 本文件不改写用户确认稿，只区分“可支持的题材”“当前不能说死的强结论”。预拍可继续，公开发布资格需在原片到位后再次复核。

## 已有可靠证据支持的内容

1. 婚礼定制、家庭故事动画、老照片修复、人生回忆录等服务在市场上确实存在；但具体价格、制作质量和交付周期差异很大。
2. 中国传媒大学公开的 AI 口述史调研项目实际做过社区、养老机构和家庭场景的小规模试点，并把散点回忆整理为家族档案和可视化时间线。
3. 地方政府公开报道中确实存在面向中老年人的 AI 与数字技能课程，内容包括文生图、图生视频、短视频制作和手机应用。
4. Pexels 备用素材许可允许个人和商业用途；这些画面只能作为场景示意，不能冒充本人客户或本人项目。

## 当前证据不足，发布前必须重点复核的原句

| 原句口径 | 当前问题 | 画面处理边界 |
|---|---|---|
| “万播也就几块钱”“万播几块钱” | 不存在统一、固定、适用于所有账号的平台收益口径 | 不展示固定收益数字，只显示“结果不定” |
| “真真能落地马上能变现”“真正能快速拿到现金” | 属于结果和速度承诺，未经本地真实成交样本支持 | 不做现金、订单或立即回款画面 |
| “做完一单收一单的钱”“谈成就有收入” | 把交付、验收和回款说成稳定因果 | 只展示需求、交付、验收与修改分支 |
| “动辄几万十几万……几千就搞定” | 商业报价差异极大，现有公开页面不能支持普遍替代关系 | 婚礼纸艺镜只讲制作流程，不出现任何价格 |
| “做了本地部署，成本更低” | 是否更低取决于规模、硬件、运维和调用方式 | 不用动画表达必然降本 |
| “需求特别旺盛” | 有项目和小规模试点，不等于已证明本地付费需求旺盛 | 使用“项目存在”的证据，不使用排队、爆单画面 |
| “竞争对手反而很少” | 兰州本地竞争数量尚未形成可核验清单 | 纸艺对照只表达两条路径，不标竞争者数量 |
| “三线城市” | 城市线级并无统一官方划分 | 画面使用“兰州、本地、西北”，不展示城市等级标签 |

## 当前结论

- 题材成立，可以继续预拍与素材准备。
- 用户确认稿保持逐字不改。
- 纸艺与真实素材不得替强结论“作证”。
- 原片到位后，实际声音是唯一字幕正文；发布前仍需用户决定是否保留上述强口径，或采用有证据边界的表达。
